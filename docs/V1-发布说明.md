# JainkAI V1 发布说明（v1.00，2026-11-04）

> 一个用 C11 写的**白箱 AI 内核**：记忆是一张图（词＝节点、关系＝边），推理是图上求解 + 验证，
> 所有"改自己脑子"的动作都走**提议 → 审查 → 预算 → 应用 → 审计**。
> 没有神经网络生成文本，没有调用大模型。

### 1.1 这版新增的东西

- **代码合成** `::code synth <中文描述>`：任务→关键词→**骨架**→可编译 C（程序自带自测）；
  `codebench` A 3/3、B 15/15、C1 0/15（消融必须 0）、C2 12/15、D 15/15。
- **可教**：`tools/teach_skeleton.sh` 一条命令把"新任务"教进去（7–8 条三元组 + 一个自测程序），
  教完立刻 `::code synth` 验证"编过、测试全绿"。实测 15 个新任务：10/15 → 15/15。
- **真知识抓取管道**（离线可用）：`tools/pipeline.sh` 管四条源（Debian/Ubuntu/PyPI/RubyGems）+
  转分片（`.c7b2` v2 + gzip，**7.4 B/边**）+ 镜像自动切换 + 看护；累计 **2.4 亿条真边**。
- **跨分片查询** `::parts corpus find <名字> <目录>`：511 片 48 秒扫完（`printf` 命中 52 片 235 条）。
- **后训练工具**：`::batch` 巩固/抽象/睡眠回放；`tools/ab_dialog.sh`、`tools/model_metrics.sh` 量化对比。
- **速度画像**：`tools/bench.sh`（载入/单查询/吞吐/RSS）。

## 2. 快速开始

```sh
# 编译（C11 + libc，约 20 秒）
gcc -std=c11 -O2 -Wall -Wextra -Wpedantic -Werror -o build_aip main.c -lm

# 对话
./build_aip --model model.bin
你 > 猫 属于 动物
你 > 猫 会 飞 吗
你 > ::help

# 写代码（要先有代码图）
sh code/build_code_model.sh                      # 生成 code/code_model.bin
./build_aip --model code/code_model.bin
你 > ::act on
你 > ::code synth 写一个程序：求两个数的最大公约数。

# 教它一个新任务
sh tools/teach_skeleton.sh 温度转换 华氏,摄氏,温度 ./f2c.c code/code_model.bin

# 全部回归
sh tests/all.sh
```

## 3. 已知边界（照实说）

- **代码能力 = 骨架库的覆盖度**：同类任务换个说法能匹配；没教过的任务类型会明确说"没有匹配的任务"，
  不会瞎编一个编不过的程序。
- **知识靠语料**：没写进图的事推不出来；抓来的 2.4 亿条真知识目前走**查询路径**（`::parts corpus`），
  还没灌进对话模型（灌 1 万条试过：图变大、问答变慢 43%、注入的知识答不出来 ⇒ 要靠"问题→查询"的桥）。
- **网络是扩图硬约束**：链路被限速到 ~50 KB/s 时吞吐掉到 1/10。
- **性能**：`::rel` 11.8 µs 与图规模基本无关；但**端到端问答**随图变大而变慢（15 MB/41 k 边时 5.3 ms）。
