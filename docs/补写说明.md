## 二、补写的实现要点（对齐分享里的原话）

- `token_lang.h` **不再定义** `token_remove_assoc`，用的是 `token.h` 里那一个；
- 提供分享里点名的东西：`PrimKind`、`Interp`、`pool_init_prims`、`interp_exec_prim`、
  `token_run*`、`focus_selector_*`、`token_run_focus`、`token_activate_lang`；
- `ai.h` 里 `ai_gc` 是**三遍**：① 衰减 hits + 按 hits 巩固 + 裁到 `max_assocs` + 摘掉已遗忘的边
  ② 遗忘（`mem_state` 概率升级）③ **直接删** `FORGOTTEN`——**没有** `gc_max_population` 门槛；
- `ai_pick_next` 过滤 `mem_state >= MEM_DORMANT` 的边和终点；
- 代码里**没有一处** `e->hits++`，全部走 `token_touch` / `token_touch_entry`；
- `agent_step` 末尾：

  ```c
  if (ai->gc.gc_interval && (ai->turns % ai->gc.gc_interval) == 0)
      ai_gc(ai);   /* 内部现在会立即删 FORGOTTEN */
  ```

- 依赖方向按分享里的图：`main.c → agent.h → ai.h → token.h`，`token_lang.h → token.h`。

**属于我自由设计的部分**（原文不在，只能自己定）：原语的具体集合与语义、分词规则
（空白 + 标点切分，CJK 按字切）、种子语料、元命令清单、生成时的加权方式。
这些都不是从对话里还原出来的，只是能跑通、能 debug 的一版。

## 五、已验证

- `gcc -std=c11 -Wall -Wextra -Wpedantic` 零警告；CMake 构建通过；
- `-fsanitize=address,undefined` 下跑完整会话（学习 / 生成 / GC / 遗忘 / 存盘 / 读盘 / 汇编）
  无报错；
- 存盘 → 读盘后 token 数不变（v3 格式回环）。

## 六、已知限制

- 程序指令用关联边表示，操作数放在 `e->subs` 里，所以一条指令最多 4 个操作数
  （`TOKEN_CTX_MAX`）；`observe` 因此最多吃 4 个词。
- `token_pool_dump` 不序列化 tick / `mem_state`，读盘后所有对象都是 ACTIVE、tick 归零。
  （**模型存盘不走这条老路**：`model.bin` 用 `model_io.h` 的完整快照，tick /
  `mem_state` / `birth_tick` / `last_touch_tick` / `next_in_time` / 视角 / AI 层全部保留。）
- 遗忘只作用于非类别 token（原语、智能体的「我/感知/思考/行动/维护」不参与遗忘）。
