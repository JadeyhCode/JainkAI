# 人的思考原理：**采用什么、不采用什么**

> 用户两条指令（原话）：
>
> > **「越接近人思考的原理越好」**
> > **「但是不要把糟粕学来了」**
>
> 这份文档把这两句变成可执行的判据：哪条原理可以学、它落在哪一层、**凭什么说它真的在跑**；
> 哪条是糟粕、挡住它的**护栏**在哪、哪套回归会当场变红。
> 配套看护：`tools/biastest.c`（C 级，35 项）+ `tests/biases.sh`（CLI 级，10 项）。

---

## 一、判据：什么才算「接近人的思考原理」

一个机制要够格，必须同时过三关（缺一条就别加）：

1. **功能关**：它在人身上是**干活的**机制，而且能说清它解决什么适应问题。
   说不清适应问题的，多半只是**名字像**（比如把某个阈值改名叫「注意力」）。
2. **落地关**：它必须落在**已有层**上（图 / 关系 / 思维 / 微内核），
   读表、读图、读表示 —— **不许为了它写一条新的 if-else 知识**
   （见 `docs/设计原则-涌现与脑区.md`：机制可以新写，知识必须涌现）。
3. **护栏关**：它必须配一条**反糟粕护栏**。这一条最容易漏，也是本文的重点 ——
   人的原理之所以有效，往往正因为**它带着约束**：
   记忆强，是因为**惊讶 + 会遗忘**；因果学习强，是因为**要协变 + 会被反例推翻**。
   只学前半句，学来的就是偏误。

第三条是这个仓库反复踩出来的两类坏味道：

| 坏味道 | 症状 | 这一轮的实例 |
|---|---|---|
| **机制在、行为不在** | 声明了某个机制、计数器也在涨，但它对图/行为**没有影响** | `ai_learn_counterfactual` 调 `ai_weaken_edge`，而后者要求 `n_subs==0`；因果边带 `[因果]` 语境 → **永远匹配不上**，`反事实=` 每次 +1 却什么都没改 |
| **机制在、约束不在** | 原理的"前半句"实现了，约束没实现 → 学来偏误 | `ai_learn_causal` 只看时序相邻：一次巧合就建一条 `hits=0`、状态=活跃的边，**出现一百次和出现一次没有区别** |

## 三、不采用表（糟粕）：偏误 → 护栏 → 钉住它的回归

| 糟粕（人的偏误） | 为什么不能学 | 本项目的护栏 | 谁钉住它 |
|---|---|---|---|
| **迷信 / post hoc**：一次时序相邻当因果 | 会把巧合固化成"规律"，越用越硬 | `[因果]` 猜想：一次 = 暂时；协变 `AI_CAUSAL_MIN_HITS` 次才升格；重复有上限；**永远不走边、不进关系表** | `biastest` ①、`biases.sh` ① |
| **确认偏误**：只找支持自己的证据 | 系统自我印证，错误再也推不翻 | 矛盾检测**正反都问**；**缓存不许互为依据**；统计只看观测（`rel_excl_build` 跳过缓存） | `delibtest` ③/⑫、`biastest` ④ |
| **虚构 / 编造**：答不上来也硬答 | 比"不知道"糟得多 —— 会自信地说错 | `gaps>0` 不下断言；拒答说法池；三态"不知道"；说不清就带保留地说 | `biastest` ③、`biases.sh` ②、`thinking.sh` |
| **近因即真理**：只留最新、抹掉过去 | 用户教的修正该留下，但历史不该被删 | 改口**只改极性位**、边还在；只限同一对词/同一关系；缓存/观测分档 | `revision.sh` ①②③ |
| **锚定 / 从众**：别人说的当成自己的知识 | 我的知识和别人的看法一混，就再也不能说"我不知道" | 他者信念表独立、视角只是标注；他的看法不进我的图 | `belief.sh`、`biastest` ⑥、`biases.sh` ③ |
| **过度泛化**：一个例子推广成规律 | 把噪声当知识 | 独占/多值要**似然比 + 样本量**（`REL_EXCL_MIN_SUBJ`）；类比置信度封顶并标明是猜 | `biastest` ⑦、`exclusivity.sh` |
| **空想当真**：白日梦变成记忆 | 想象会污染知识库 | 想象只挂 `[想象]` 标记的合成节点；内心排练只动**注意力权重**（图一动不动） | `biastest` ⑤ |
| **情绪放大**：一次惊吓固化成信条 | 单次强情绪不该改结构 | 惊讶只**削弱**那条预测边、几何衰减、有下限；只动参数层 | `biastest` ②、`features.sh` 7 |
| **自我服务 / 归因失衡** | 因果归因会越来越偏 | 反事实只削弱带 `[因果]` 标记的边，**削不到就不计数** | `biastest` ② |
| **把报表当事实**（工程味的一条） | 计数器涨了不等于机制在跑 | 判"机制在不在"一律看**可观测量**（边的 hits/状态/答案），并专门测"削不到时不计数" | `biastest` ②、`biases.sh` ① |

## 四、这一轮修的那个洞：**因果要协变，反例要算数**

改动前的实测（`tools/causalprobe.c` 的探针，改前 / 改后各跑一次）：

```
一次巧合之后：  边 猫 -> 鱼 : hits=0 mem=0（活跃）n_subs=1 sub0=[因果]     ← 一次=永久、和一百次没区别
重复 4 次之后： 边 猫 -> 鱼 : hits=0 mem=0（活跃）n_subs=1 sub0=[因果]     ← 重复什么都没改变
反事实之后：    边 猫 -> 鱼 : hits=0 mem=0（活跃）  n_counterfactual=1     ← 计数器说削弱了，边没变
```

改动后（**这个探针留在仓库里**，`./build_causalprobe` 直接看）：

```
① 一次：       边 猫 -> 鱼 : hits=1 mem=1（暂时） 语境=[因果] walkable=0
② 协变到 4 次：边 猫 -> 鱼 : hits=4 mem=0（升格/可信） 语境=[因果] walkable=0
③ 反复 60 次： 边 猫 -> 鱼 : hits=8 mem=0（升格/可信）   ← 有上限 AI_CAUSAL_HITS_CAP，刷不成事实
④ 反事实到 0： 边 猫 -> 鱼 : hits=0 mem=2（雪藏）  反事实计数=9（只在**真的削弱**时才涨）
⑤ 见得多也不是知识：rel_direct(猫,属于,鱼)=0  rel_direct(猫,有,鱼)=0  走边可行=0
```

三条**护栏**保证「见得多」不会把它变成知识（`tools/biastest.c` 逐条钉住）：

1. 永远带 `[因果]` 语境标记 → 关系层/知识查询（`rel_direct_*` 要求 `n_subs==0`）认不出它；
2. 永远不参与走边（`ai_edge_walkable` 挡掉带语境的边）；
3. 升格只写 `hits`/`mem_state`（**参数层**），不建新边、不改结构。

参数集中在 `ai.h` 的参数区：`AI_CAUSAL_MIN_HITS`（协变几次升格）、`AI_CAUSAL_HITS_CAP`（重复上限）。

## 五、缺口（照实说，别假装都有）

| 缺的原理 | 现在差在哪 | 要做的代价 |
|---|---|---|
| **修正的记忆**（"我以前以为…"） | 改口之后只剩新极性；旧说法不留痕（只有当轮 COT，不进存档） | 需要一份**不冒充知识**的来源记录；可能动存档格式 → 暂缓 |
| **结构映射式类比** | 只有 emb 向量算术，撑不起「A 之于 B 如同 C 之于 D」 | 仓库既有结论：表示层质量不够 → 暂缓 |
| **情绪真正参与决策** | 内感受目前基本只影响参数与提示（惊讶 → 削弱那一条） | 要让舒适/唤醒进入取舍，得先有一批真实会话数据校准 |
| **时间/顺序推理** | 只有 `[时刻:N]` 标记与 `next_in_time` 链 | 需要一套区间/先后关系的规则，属新脑区 |
| **未解问题持久化** | 会话内够用 | 升格式 + 重训 |

## 六、检查表（加一条「人的原理」之前先问）

- [ ] 它是**功能机制**，还是只是名字像？（说不清它解决什么适应问题 → 名字像）
- [ ] 它落在**已有层**上吗？还是我又写了一条知识（if-else/清单）？
- [ ] **它的约束是什么**？（没有约束的原理 = 偏误；只学前半句就是学糟粕）
- [ ] 护栏**能跑红**吗？（要有回归，不是文档里一句好话）
- [ ] 可观测量是什么？（不许拿计数器自证：要看边、权重、状态、答案）
- [ ] 我有没有把「人的局限」当特性学进来（近因、锚定、泛化、过度自信）？
- [ ] 我有没有把"机制在"当成"行为在"？（`grep` 到函数名不算，要看到它改了什么）
- [ ] 我把「为什么这么定」和**没做**的缺口写进 docs 了吗？
