# 说法数据层（`patterns.txt`）—— 写之前先读这一页

> 目的：**加一种新说法不用改 C**。这里记的是"怎么加、怎么验、哪里会踩坑"。
> 数据层不改变"理解"本身；它只把**已知意图的不同说法**映射到已有能力上。

## 1. 桶（一行一条，`#` 注释；` #` 之后是行内注释，会被剥掉）

| 桶 | 写法 | 作用 |
|---|---|---|
| `[lead]` | `[lead] 说错了` / `[lead] 请问?` | 句首引导语，剥掉后走正常流水线；**尾部 `?` = 问句引导语**（剥掉后余句没 吗/呢 就补一个，否则问句会被当陈述学；§6.374） |
| `[slot]` | `[slot] 哪一类` | 占位/含糊的问法 |
| `[confuse]` | `[confuse] 我不明白` | 含糊回话 |
| `[reply]` | `[reply] 组,组=答复文本` | 直接答复；`组,组`=AND、`组内 a\|b`=OR、行首 `^`=**整句精确匹配**。<br>⚠ `^` 只对**整行**生效：`^你在吗\|^你在么` **不是**"两个精确匹配"，而是一个不存在的整句串（§6.392 踩过）——要两个就写两行 |
| `[shape]` | `[shape] $1@k 你 $2@r 吗 = 你 $2 $1 吗` | 整句改写（**核心工具**） |
| `[syn]` | `[syn] 猫咪=猫` | 分词前**子串**替换（长的先替）；词级同义也在这里（§6.365） |
| `[affix]` | `[affix] 小=pre` / `[affix] 们=post` | 词缀变体：基词在池里才剥 |
| `[fill]` | `[fill] 真的` / `[fill] 确 实` | **副词填充**：句中出现就整段删（按分词写；§6.375） |
| `[bare]` | `[bare] 肯定=对,是,嗯` | §6.533 **裸短回话词表**：三组（肯定/否定/不懂），逗号分隔；整句只说这些时不算知识、不掉流水线；措辞在 `[say] 回话.*`（§6.533）|
| `[say]` | `[say] 组织.定=$1 ， $2` | §6.532 **答复组织**：键是语义位（`判词.对/不对/不定`、`组织.定/符号/猜一/猜多/假设/缺/空`），模板里 `$1`/`$2` 是槽位；改措辞 = 改这一行（§6.532）|
| `[qword]` | `[qword] 吗` / `[qword] 为什么` | §6.531 **疑问词表（整词）**：一个 token 就是它才算问句；patterns.txt 是唯一来源（代码里只留"没有数据时"的种子表）|
| `[qpart]` | `[qpart] 什么` / `[qpart] 多大` | §6.531 **疑问词表（子串）**：词里含它就算问句，只对 2 个汉字以上的词生效（`多少钱` 被分词并成一个词时，整词表看不出它是问句）|
| `[class]` | `[class] attitude=讨厌,愿意,嫌我` | **词类**：`[reply]` 的关键词组里写 `@attitude`，类里任一词出现即命中（§6.393）。<br>⚠ 类行必须写在**用它的 `[reply]` 之前**；行内容较长，别被通用长度检查吞掉。<br>一个组里可以**类 + 字面量混写**：`@timeword\|未来\|外面`（等同"这些词任一出现"，§6.395） |

`[shape]` 占位符：`$1..$9`；`@k` = 必须是词池里的词、`@r` = 必须是已知关系；
会话变量 `$S`（上轮主语）/`$P`,`$R`（上轮问句宾语/关系）/`$A`,`$W`,`$O`（上轮陈述的主语/关系/宾语）。

## 2. 加一条规则的标准流程（按这个顺序，别跳）

1. **先写留出集**（`tests/holdoutN.txt`），**写题时不看规则**，跑一遍记基线：
   `sh tests/holdout.sh session.bin tests/holdoutN.txt`
2. 加数据行 → 重跑留出集（数字必须动）
3. `sh tests/datacheck.sh`（查数据行会不会把"学得到"变成"学不到"）
4. `sh tests/attrib.sh`（看这条能力是数据给的还是内核本来就有的）
5. `sh tests/all.sh`（42 套，必须全绿）
6. A/B：`AIP_RB_SAVE=/tmp/ab_N.bin ./build_roundbench model.bin 100`，与 `/tmp/base_v14.bin` `cmp`

## 3. 诊断开关

| 环境变量 | 作用 |
|---|---|
| `AIP_PATDBG=1` | 打印各桶加载了多少条；**超上限会打 ⚠ 并丢弃**（每次启动都该看一眼） |
| `AIP_SHAPEDBG=1` | 形状引擎逐条：`输入分词 N: …`、`近失: 规则`、`命中: 规则 => 改写结果` |

## 4. 已知的坑（都踩过，按代价排序）

1. **分词结果和你想的不一样**：`杭州` 是 `杭/州`、`鲸鱼` 有时一个词有时 `鲸/鱼`、
   `一只`/`这只`/`会不会`/`对吗` 都可能被合并或拆开。**一条规则要按实际分词写**；
   换模型/换会话可能变，必要时两种写法都留。
2. **形状行的 rhs 必须落在已有答复路径上**（问句 → 开放问题，或命中 `[reply]`）。
   写成一句新的陈述句 ⇒ 改写成功但整句掉兜底（§6.314 实测）。
3. **`[reply]` 是子串匹配**：`教我` 会把「教我猫属于动物」抢走（§6.312）。
   凡是可能**带内容**出现的关键词，用 `^` 精确匹配或写成更长的固定短语。
4. **上限静默丢弃**（`[reply]` 现在也会打警告；§6.351 抓到 64 上限丢了 5 行）：`AIP_SHAPE_MAX` / `AIP_REPLY_MAX` 满了会丢后面的行（以前是静默的，
   现在会打 ⚠）。加行后一定看 `AIP_PATDBG` 的计数。
   §6.371 起，加载器会**默认**在启动时对一次"文件行数 vs 进表行数"，对不上就打
   `⚠ [桶] 文件里 N 行、实际加载 M 行` —— 加完行直接看启动输出即可，不必再手动数 `AIP_PATDBG`。
   **另有一个按行的长度上限**（§6.370）：`[reply]` 的**关键词串**（等号左边整串）超过 512 字节、或
   答复文本超过 1024，整行被丢。实测一个"+6 个时间词"的长行在旧的 128 字节缓冲上被**静默吞掉**
   （`reply=55` 而文件 56 行）。加长行之后**必须**用 `AIP_PATDBG=1` 对一次计数。
5. **词缀会撞名字/词汇化**：`小明` 不能剥成 `明`、`大学生` 不能剥成 `学生`（§6.307）。
   现在的护栏：前缀不剥单字基词、整词在池就不动、人称代词+`们` 不剥。
6. **并发跑度量会互相干扰**（临时目录/子进程）：同一时刻只跑一份（§6.315）。
7. **`[syn]` 是子串替换，别写会嵌在别的词里的字**（§6.365）：`爱=喜欢` 会把 `喜爱` 拆成
   `喜`+`喜欢`（`relations` 套件当场红）。要么写成更长的词（`最爱=最喜欢`），
   要么先把被嵌的那个词单列一行。`寂寞=孤独` 这种也常见：**目标词本身听不懂** ⇒ 死行。

## 4a'. **管线顺序**：改写只能指向"改写之后才会跑"的路径（§6.384/§6.386 连踩两次）

`[shape]` 改写发生在管线**中后段**。下面这些判据看的是**改写前**的原始串（或更早的分词结果），
所以**把句子改写成"只有它们才认"的形式是无效的**：

| 判据 | 看什么 | 踩过的例子 |
|---|---|---|
| §6.270 量/尺度 | 改写前原始串（`有多大/多重/多长…`） | 把 `X 的体重是多少` 改写成 `X 有多重` ⇒ 答出「重 要」 |
| §6.212 名字反查 | 改写前的**分词结果**（`[X][是][谁]` 三词） | 把 `X 是谁` 改写成 `X 是 谁` ⇒ 无效（不空格时 `是谁` 是一个词） |
| §6.269 保证请求 | 改写前原始串（`你确定/真的吗`） | 未踩，同理 |
| §6.268 省略式 | 改写前分词（`那X呢`） | 未踩，同理 |

**规则二之一：`[shape]` 改写**只做一次**（§6.444/§6.456）**
把一句话改写成"另一种说法的标准形式"，指望它**再被另一条形状接住**——不会发生。
形状引擎对同一轮输入只改写一次，改写结果直接进后面的层。实测两次：
`在杭州的猫算什么` 想靠通用行改成 `猫 算 什么` 再匹配、`猫和狗谁算动物` 想改成 `都算` 形式再匹配，
**都失败**，必须让这一行直接写出最终问句（`= $1 属于 $2 吗`）。

**规则二：`[shape]` 是"先匹配先赢"**
同一句话可能同时匹配多条形状，**排在前面的先改写**，后面的再也看不到它。
实测踩过：`猫算动物对吧` 先被通用行 `$1 $2 $3 对吧` 改写成「猫 算 动物 吗」（"算"不是关系）⇒ 兜底；
把专用行 `$1@k 算 $2@k 对 吧` 挪到通用行**之前**才生效。**越专用越要放前面。**

**规则三：形状要照"分词"写，不是照汉字写**
`你以为` 分词是 `你/以为`，`我想知道` 是 `我/想知道`，`岂不是` 是 `岂/不是`。
按汉字整词写（`[shape] 你以为 …`）**永远匹配不到**。写之前先用
`AIP_SHAPEDBG=1` 看「输入分词 N: …」那一行。

**`[shape]` 的可变长度填充 `@x`（§6.482/§6.483）**

写法：`@x` 表示"**1~8 个 token 的任意填充**"，加载时展开成 8 条（`$5` 重复 1~8 次；`$5` 只在 lhs 出现、rhs 不引用）。

```
[shape] @x 的 $1@k $2@r $3 吗 = $1 $2 $3 吗      # 被称为动物的猫会飞吗 ⇒ 猫 会 飞 吗
```

三条**踩过的坑**：
1. **插入位置**：展开必须在 shape 分支**最后一个 `continue;` 之前**（分支内先有"超上限就丢"的早退 `continue`，
   放它之前整行会被跳过、`shape=0`）。这个坑踩了三次（§6.475/§6.481/§6.482）。
2. **`@k` 需要词池**：在 `ai_new()` 没有模型的复现器里，`$3@k` 永远不成立；用 `$3`（不要求已知）才稳。
3. **展开会把行数放大 8 倍**：一条 `@x` = 8 条（占 `AIP_SHAPE_MAX`），别滥用。

**行为模块的四套写法（§6.507–§6.526，统一看这张表）**

| 写法 | 用在哪 | 含义 | 坑（都踩过） |
|---|---|---|---|
| `A&B` / `A\|B` / `!A` | `加条件` 的条件词 | 与 / 或 / 非（`!` 可连写） | 不短路；判不了会向上传染 |
| `#N` / `#N:过` / `#N:认不全` / `#N:复核不过` | 条件词 | 第 N 步「加断言」的结论**与缺口类型** | 没跑过的步 = 判不了；认不出的类型 = 判不了 |
| `$1`..`$4` | 断言 / 条件 / `加说` 模板 / `加执行` 命令 / 对话 `跑 <过程> 实参…` | 这次跑的实参 | 缺了**原样保留** ⇒ 认不全断点；实参只做文本替换、无 shell 转义 |
| `加说 <过程> <模板…>` | 行为表 | 过程"说的话"；`跑 <过程>` 时**有 say 就答它** | 多步用空格拼接；对话入口超 4 个实参会明说 |

**外壳（引导语）的两种来源**
- `[lead] 词?`（桶，**镜像数据源**）：`?` 表示问句框架（剥完补问号）；
- `::op 标外壳 <词> [问]`（图上记号）：`词 —[外壳]→ 外壳标记`，带问时动作槽挂 `[外壳:问]`。
- **剥离时只读图**（§6.520 起默认）：桶在加载时镜像成 `[外壳:词]`/`[外壳问:词]`（不进分词）；
  `AIP_SHELLMIRROR=0` 关镜像、`AIP_SHELLONLY=0` 退回"查桶"老行为（A/B 用）。
- 缓存按**版本号**（`g_shell_epoch`）失效：标一个已在池里的词也立刻生效（§6.521）。
- **撤销**：`::op 撤外壳 <词>`（§6.530）删掉那条 `词 —[外壳]→ 外壳标记` 边，缓存同版本号立刻失效；
  三种撤不掉的情况会**明说**：词不在池里 / 没有标记边 / **来自 `[lead]` 镜像**（要改数据行）。
- §6.530 起，`agent_step` 里那张写死的引导语表（`教你/告诉我/记住/teaches…`）**已退役**、搬成 `[lead]` 行：
  外壳只剩两条入口 —— 数据行（→镜像）或 `::op 标外壳`（→边），没有"代码里偷偷再来一套"。

**过程/条件的三种"数据写法"（§6.507–§6.510）**

| 写法 | 用在哪 | 含义 | 坑 |
|---|---|---|---|
| `A&B` / `A\|B` / `!A` | `加条件` 的条件词 | 与 / 或 / 非（`!` 可连写） | 不短路；判不了会向上传染 |
| `#N` | 条件词 | **第 N 步「加断言」的复核结论**（1 过 / 0 不过 / 没跑过=判不了） | 步号 ≥64 记不下（现在会明说） |
| `$1`..`$4` | 断言/条件 | 这次 `::proc run <名> <实参…>` 绑的实参 | 缺实参**原样保留** ⇒ 认不全断点；实参只做文本替换、无类型校验 |

**三条纪律**：① 判不了**不静默当成立**；② 记不下/截断**要明说**（§6.510）；③ 新增一种写法 = 加进这张表 + 加 tokenop 用例。

**测量口径：改写变体必须注明是否改变句式（§6.505/§6.506）**

疑问句去掉尾部 `吗` 会变**陈述句**，系统会把它**学进记忆**并回声「记下了：…」——那不是"答出来了"。
所以写"换问法"型测量时：① 只用**保持疑问**的变体（`+吗`、`+呢`）；② 报告时注明变体类型。

**数据卫生：形状里不许写死实体（`patcount` ⑨）**

`[shape]` 的 lhs 出现 `猫/狗/鲸鱼/鸟/鱼/猪` ⇒ `patcount` ⑨ **判失败**（写死实体 = 把测试集当训练集）；
出现 `动物/哺乳` 这类**类别词**只给提示（可能是习语，如 `会X的动物都有什么`）。

**检查命令**（也可手动）：`grep "^\[shape\]" patterns.txt | grep -cE "猫|狗|鲸鱼|鸟|鱼|猪"` 应为 **0**。

**⚠ 动上限之后必须做的两件事（§6.477/§6.478 血的教训）**
1. 跑 `sh tools/asan_check.sh`（它有生命周期/随机句/病态/非法字节/变异/命令面六组）——**只看套件绿不够**；
2. 拿**长句样例**（≥12 token，贴近新上限）各跑一条，确认不崩。

原因：`AIP_SHAPE_TOK` 从 8 放到 16 时，暴露了两个**原有隐患**——`lead[]` 数组漏 `NULL` 结尾、
`ww[]` 只填前 12 个；两者都让 14 token 的句子直接**段错误**，而 45 套件当时全绿。

**换说法到底靠什么层（§6.457–§6.464 实测，都是"改动前写"的探针）**

| 做法 | 例子 | 转移率（新说法上的通过率） |
|---|---|---|
| **词级归一**（`[syn]` 把谓词/外壳换成本词） | `算作/该算/归到/被当作 = 属于`；`行吗/没问题吧 = 吗` | **56%**（genprobe5 基线 9/16） |
| **结构行**（`[shape]` 整句语序） | `$1 到底 算 不 算 $2` | **19%**（genprobe4 基线 3/16） |
| **外壳剥离**（词级） | `被算在/被视作 = 属于` | **12%**（genprobe9 基线 2/16）——每个外壳都要单独一条 |
| **外壳 + 动词槽**（`[shape]` 留动词位） | `X 被 _ 作 Y 吗`、`X 被 _ 为 Y 吗`、`把 X 属于 Y 吗` | **31%→81%**（genprobe11 基线 5/16 → 13/16），且**跨探针 +1~2** |


结论：**词表（`[syn]`/词级归一）比整句形状更能转移**；但两者都**不处理语序**
（`把鲸鱼算作鱼类对吗`、`猫被算成动物了吗` 这类仍然不行）。

五个坑（都踩过，§6.484 补后三条）：
0. **`[reply]` 关键词不能带空格**：输入先去掉空格再比，`依 据` 永远匹配不上（写成 `依据`）；
0. **专门的形状行要排在通用行之前**：`@x 的 …` 这种泛化行会把「会被猫追的动物是狗吗」抢走，
   必须把倒装/特例行写在它上面（形状是"先匹配先赢"）；
0. **`@r` 只认静态关系**：`追` 是动态学来的关系，`$2@r` 不成立 ⇒ 用 `$2`（不要求关系）才匹配得上。


1. `[syn]` 右值**不能为空**（`[syn] 的一种=` 整行被丢弃）；

## 4b. 语法坑（§6.341 新增两条）

- **规则里不要用 `=` 当标记**：加载器按**第一个 `=`** 切 lhs/rhs，
  `$3@=2` 会把规则切成半截、**静默失效**。要"同词约束"用 `$3@s2`（= 与第 2 个占位符同词）。
- `[reply]` 的关键词里**绝对不能有空格**（含 CJK 之间）：输入去空格匹配、关键词不去
  ⇒ `给 我`/`写 首` 永远匹配不上（§6.360 抓到 2 行）。多字要连写（`对吗` 不是 `对 吗`），
  而且 `组,组` 的 AND 是"各自出现一次"——**没法要求同一字符出现两次**（所以逗号并列做不了）。
- `aip_patterns_load(NULL)` 会崩（变体生成要查词池）；写 dump/探针工具时先建 `AI`。
