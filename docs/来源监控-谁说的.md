# 来源监控：这条知识是**哪来的**（谁说的）

> 用户点过的：「顺便继续修正的记忆 / **来源监控**」，以及 6 条清单里的
> **#1 来源监控补「谁说的」**。
>
> 一句话：把"**基准教的**／**我自己经历学到的**／**我想出来记住的**／**他说的**／
> **假设里成立**"分得开，而且**说得出来**。

---

## 一、五档来源（能分，才谈得上"监控"）

| 档 | 是什么 | 存在哪 | 判据 |
|---|---|---|---|
| **基准** | `relations.txt` / 内置词表**显式教**给它的知识 | 我的图（`role=ASSOC_ROLE_INNATE`） | `assoc_role_is_innate(e)`；每次装载 `relations.txt` 重打标 ⇒ 确定性 |
| **观测** | 对话/语料里**自己经历**学到的（`role=0/1/2`，含造词 3） | 我的图 | 其余档之外的默认 |
| **推论** | 想出来**沉淀**的缓存（`role=ASSOC_ROLE_DERIVED`） | 我的图 | 求解器认得出（`ProofStep.known`），证据强度按缓存算，还要求"脱离缓存也推得出" |
| **他说的** | 别的人告诉我的看法 | **他的表**（`OtherModel.bel`，v8 存盘） | `other_belief_find()`；**绝不进我的图** |
| **假设** | 反事实里临时成立的（"如果…"） | 假设层（不存盘） | `hypo_find()` |

这五档本来就**分散**在不同的机制里（role 字段 / 他的表 / 假设层），缺的是
**一个地方把它们摆在一起说清楚** —— 这一轮补的就是这个。存档格式**没动**
（`role` 一直是序列化字节，新值只是新语义；旧模型读回来就是"观测"）。

## 二、`::src <A> <关系> <B>`：一条知识的**来源账**

```
你 > 他 说 猫 会 飞
AI > 记下 了 ： 他 说 猫 会 飞 —— 可 我 知道 实际 上 不 是 这样
你 > ::src 猫 会 飞
[来源账] 猫 会 飞
  我的图：不是（来源=基准，命中=32，首次 seq=257）
  推得出来吗：推不出来
  他说的：他 说「会 飞」（他的表，不进我的图） —— **和我的图相反**
  假设层：没有
你 > ::src 猫 属于 动物
[来源账] 猫 属于 动物
  我的图：是（来源=基准，命中=56，首次 seq=1）
  推得出来吗：成立（依据档 观测事实；验证器 通过）
      链：猫 -[属于]-> 动物
  他说的：没听谁说过这条
  假设层：没有
```

四问四答：**我的图里有没有、是哪一档**（基准/观测/推论 + 命中/首见）→
**推得出来吗**（求解器 + 证据档 + 验证器 + 链）→ **他说的**（谁说过、和我的图**一致还是相反**）
→ **假设层**（只在"如果…"里成立的那些）。

`::edges <词>` 每条边现在也带来源：

```
  → 动物   hits=56  seq=1  角色=5 状态=0 来源=基准
  → 天     hits=293 seq=79 角色=2 状态=0 来源=回复
```

（`角色=N` 是原样保留的老字段，**后面追加** `来源=xx` —— 钉住旧格式的看护不用改。）

## 三、矛盾里也说清"两边各是哪来的"

`::delib` 的矛盾那一行以前只说"正反都推得出来（另一边依据强度：X）"，
现在两边都带来源档（`der_base_source`：看链上第一个落地的步子，那条边的 role）：

```
正反都推得出来（正面来自 基准，反面来自 推论·依据强度 缓存）：猫 -[属于]-> …
```

"我知道的 vs 我推出来的"和"我推出来的 vs 我推出来的"是**两件不同的事**，
以前分不开，现在分得开。

## 四、顺带确认的两条老纪律（测试里钉住了）

1. **缓存不许证明自己**：孤立的一条沉淀（没有任何独立支撑）**不被采信** ——
   求解器要求"脱离缓存也推得出"才用它（`rel_solve_ignoring_caches`）。
   实测写这条测试时才发现自己记错了预期，正好把它钉成断言。
2. **他的信念永远不进我的图**：`他 说 猫 会 飞` 之后，`::src 猫 会 飞` 显示
   "我的图：不是（来源=基准）"、`他说的：…和我的图相反` —— 归属清楚，各存各的。

## 五、看护与局限

* `tools/optest.c` 第十六节（10 项）：观测/基准/推论三档打得对、名字只有一份、
  `relations_load` 真走装载路径、链的底报得出来、**孤立缓存不被采信**、有支撑的缓存报"推论"。
* `tests/belief.sh` 第八节（7 项）：`::src` 四问四答、他说过且与我相反要写明、
  未知谓语说清楚、`::edges` 带来源。
* 全量 31 套仍全绿；`model.bin` 不变；**格式没动**。

局限（照实说）：

1. **"基准"只覆盖 `relations.txt`（+装载路径）**：frames.txt 与预训练语料学到的共现
   都算"观测" —— 因为它们是**经历**，不是"谁教的"。要再细分就得给每档一个来源节点（没做）。
2. **`::src` 只查 `A → B` 的方向**：反过来（`B → A`）要自己输一遍。
3. **他说的**只按 `(A, 关系, B)` 精确匹配：他说"猫会飞"、我问"猫会不会飞"能对上，
   但同义改写对不上（谓语表里是同一 id，改写不在表里就不认）。
4. 假设层只看**当前视角**（`ai->view_who`）的那一层，多层嵌套反事实不展开。
