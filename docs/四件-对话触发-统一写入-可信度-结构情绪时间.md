## #3 对话触发：自然语言 → Token 行为

`猫 和 鱼 之间 加 个 词` 这种话现在**真的干活**（以前只能手打 `::op 中间插词 猫 鱼`）。

* **窄集 + 表驱动**：四张关键词表各只有一处
  （连接词 `和/跟/与/同/、`、动词 `加/插/添/连/接`、种类 `词/词儿/token`、`前提`），
  加一种说法 = 表里加一个词；`::triggers` 把全部说法列出来。
* **宁可漏，不可误触发**：必须同时命中「之间 + 动词 + 种类词」。
  `猫 和 鱼 之间 有 什么 关系` 是提问 → **不触发**（有专门的反例测试）。
* 触发的动作**照样走受审通道**（`token_op_run`）：自然语言只是入口，不是特权。
* 实测：

```
你 > 猫 和 鱼 之间 加 个 词
AI > 好 ， 照做 了 ： 猫 —[临:中转]→ 鱼（已提出）；应用 1 条
你 > 把 猫 和 鱼 之间 加 个 前提 饿
AI > 好 ， 照做 了 ： 猫 —[前提]→ 饿 → 鱼（已提出）；应用 1 条
你 > 猫 和 鱼 之间 有 什么 关系        ← 提问不误触发
```

**踩到的坑**：分词器把「前提」切成「**前** + **提**」两个词 → 表里写「前提」永远匹配不上，
第一版甚至把它当默认分支去做"插词"了。修法是加一个**连写匹配**（一个 token 或相邻两个 token
拼起来等于候选词，返回用掉几个）—— 分词器会切词这件事，是所有中文关键词匹配的公共坑。

## #4 统一写入通道：老写入者**有账 + 可路由**

`microkernel.md` 的局限 1 是「老写入者绕过安全内核」。这一轮把它变成两句话：

1. **有账**：所有写入从 `ai_write_assoc` / `ai_write_rel` / `ai_write_count` 过，
   `ai->writes[来源]++`，来源表在 `ai.h` 里只有一处
   （感知 / 关系学习 / 内部对话 / 想象 / 睡眠 / 衰减 / 受审）。`::safe` 直接列出来：

```
[统一写入通道] 写入账：感知=3 关系学习=0 内部对话=0 想象=0 睡眠=0 衰减=0 受审=1
               路由=关（默认）（打开时**关系事实**改走受审通道；感知共现刻意直写：
               它带 hits/pattern/topic 这些观测细节，转成意图会丢信息；账照记）
```

2. **可路由**：`::safe route on`（或测量钩子 `AIP_ROUTE=1`）让**知识类写入**
   （听来的关系事实）改成提意图 → 同一条「审查 → 预算 → 应用 → 审计」的路。
   两条路**语义相同**（`MOD_TAG_REL` 内部就是 `token_tag_rel`），差别只在谁来审查。
   路由过去的写入**进审计**，所以"谁批的"看得见。

**刻意不路由的**：感知共现（`ai_learn_pair`/`[时刻:]` 链）。它带 `hits/pattern/topic`
这些观测细节，转成意图会丢信息；而观测是知识的来源，直写本来就是它的正常路径。
**这条区别写在 `::safe` 里，不藏着** —— 局限从"没人知道谁在绕过"变成"账上写清了谁直写、为什么"。

## #5 逐条可信度：我更信哪一条

`assoc_credibility(e, now)` —— **不是新字段**（格式没动），从已有字段算：
来源档（基准 60 / 观测 50 / 推论 35）+ 命中（每次 +2，封顶 +25）− 新近惩罚（每 5000 tick
−5，封顶 −20），夹在 0..100。用在三处：

* `::src`：`我的图：是（来源=基准，命中=56，首次 seq=1，**可信度=80**）`；
  他说的那条用他的 `trust` 折算（`可信度=50`）；
* `::delib` 的矛盾行：`正反都推得出来（正面来自 基准·可信度 80，反面来自 推论·可信度 35…）`；
* `::trust on`：两边差 **≥20** 时不再说"我这儿矛盾"，而是**按可信度选边**并说出来：
  `我 更 信 可 信 度 高 的 那 一 边 （80 对 40）：…`。**默认关**（这是判定改变，已 A/B）。

**照实说**：真实知识库里"两边都推得出来且差 ≥20"很罕见（规则类冲突两边都算 50），
所以测试分两段：真跑一个矛盾确认**默认不选边**；再把"更信哪一边"摆好确认**答复那么说**。

## #6 三小件：结构类比 / 情绪参与决策 / 时间顺序

### 6a 结构映射式类比
R5（借最近邻）原来只看 `emb` 余弦。现在多一条候选来源：**关系骨架**的相似度
（`rel_struct_sim`，同宾语 + 同关系位的 Jaccard；要求共同关系邻居 ≥3 且 ≥60%）。
"用词完全不同、但结构一样"的词因此也能借到答案，链上仍标 `≈（75% 像）≈>`（**推测**）。
反例测试：另一个词同样对这件事有态度、但结构不重合 → **不借它**。

### 6b 情绪参与决策
一张**耦合表**（`AI_AFFECT[]`，一行一个耦合），不是散落的 if：

| 驱动 | 参数 | 条件 | 增减 |
|---|---|---|---|
| 疲劳 | 思考步数 | 0.60–1.00 | −4 |
| 唤醒 | 生成长度 | 0.70–1.00 | +2 |
| 唤醒 | 生成长度 | 0.00–0.25 | −1 |
| 舒适 | 激活阈值 | 0.00–0.35 | +3（阈值抬高 0.03） |

**默认关**（`::drive on` 打开）：它改的是行为参数，按规矩先实现先 A/B。
`::drive` 把表、当前驱动值、**现在命中的那一行**、以及这一轮实际生效的修正全列出来。

### 6c 时间顺序
`::order <A> <B>`：按首次见到的 tick 说谁先，并给出**顺序证据**
（最早同时连上两个词的 `[时刻:N]` 标记）：

```
你 > ::order 猫 鱼
[顺序] 猫：首次见到 tick=20；鱼：首次见到 tick=24
  → **猫 先**（早 4 tick）
```

坦白说这是顺序推理的**第一步**：只比较"第一次见到"的时间，没有"先于/后于"关系、
也没有区间/因果时序（AI_RELS 里没有这类谓语，语料里也没有）。

## 附二：情绪耦合表**按实测重调**（长轮次）

登记里写着「情绪耦合只有几行、参数手调」。写了 `tools/affectprobe.c`（走**真流水线**回放，
统计每一行的命中率 + 驱动量分位 + 舒适×唤醒相关系数）之后，量出三件事**全是缺陷**：

| 量出来的 | 数字 | 后果 |
|---|---|---|
| 疲劳到不了阈值 | 两套输入的最大值只有 **0.14**（每轮 +0.001、睡眠清零 → 一个周期最多 ~0.2），阈值却是 **0.60** | 「累了少想几步」**永远不触发** |
| 唤醒到不了低位 | 唤醒 = "猜得准不准"的低通，实测 p05 也有 **0.46**，区间却是 **[0, 0.25]** | 「迷糊时少说两句」**永远不触发** |
| 两行在说同一件事 | 舒适与唤醒的相关系数 **r = 0.91**（熟输入）/ 0.23（陌生输入） | 表看着 4 行，实际独立信息更少 |

**重调**（区间按实测分位，不是拍的）：

| 驱动 | 参数 | 新区间 | 实测命中（熟输入 / 陌生输入） |
|---|---|---|---|
| 疲劳 | 思考步数 −4 | **0.08..1.00**（原 0.60..1.00） | 20% / 45% |
| 唤醒 | 生成长度 +2 | 0.70..1.00 | 63% / 96% |
| **不适**（换掉永不触发的"唤醒低"） | 生成长度 −1 | 0.90..1.00 | 24% / 65% |
| 舒适 | 激活阈值 +3 | 0.00..0.35 | 56% / 93% |
| **舒适（补对称的那条）** | 激活阈值 −2 | 0.55..1.00 | 9% / 0% |

顺带修了一个真 bug：`ai_drive_value()` 里**没有"不适"这个名字** → 新行会恒取 0.0（永不触发），
加了 `不适 → inner.discomfort`。

**局限照实说**：舒适与唤醒仍然高度相关（都源于预测准确率），
所以"保守/激进"两行本质上是同一个信号的两端；真正独立的只有**不适**（惊讶）与**疲劳**（工作周期）。
要再进一步，得先让内部状态多几个独立维度（那是动力学的事，不是调表能解决的）。
