# 现状与结论摘要（一页版）

> 目标：**做到不改代码也能听懂新说法**——靠数据（词表/关系表/骨架表/答复模板）与泛化，
> 不靠加 `if` 分支；并用**留出的新说法测试集**量化。

## 1. 结论先说

**族内能听懂，换族听不懂。**

| 情形 | 实测 |
|---|---|
| **同一族内**换词/换谓词/换施事长度 | 探针 **60~100%**（g16/g17 16/16、g18/g19 15/16、g20/g21 13/16） |
| **换一族**（从句作主语/倒装/名词化/反问求证） | 探针 **12~25%**（g20 基线 2/16、g22 基线 4/16） |
| 独立留出集（不随改动调整） | blind4 **448/470**、pert **213/275**、blind5 **131/140**、17 组 **205/212** |

三周里**唯一**让独立量尺动过的改动是 §6.482（pert 211→213，+2）。
其余改动（两族攻坚、三批词表、`@x` 顺序修复）都只让**探针**涨，量尺**纹丝不动**。

## 2. 我们证明了什么

1. **数据层可以扩展"族"**：一条 `[syn]`/`[shape]` 能覆盖一族写法（`算作/该算/归到 = 属于`、`@x` 可变填充）。
2. **数据层不能跨族**：换句式（`的`-从句、倒装、名词化、反问求证）立刻回到 12~25%。
3. **容量上限会咬人五次**：`AIP_SYN_MAX` 64、`AIP_SHAPE_MAX` 256/512/1024、`AIP_PAT_MAX` 96、`AIP_SHAPE_TOK` 8。
   已集中成表（`docs/data-layer.md`）并由 `patcount` ⑧ 监控余量。
4. **调上限必须跑 ASan + 长句**：放开 token 上限时暴露两个**原有隐患**（`lead[]` 漏 `NULL`、`ww[]` 写死 12），
   都导致 14 token 句子**段错误**，而 45 套件全绿。

## 3.5 「给事实」这个指标要小心读（§6.501）

关掉 `[reply]` 桶再跑四样本，看"给事实"掉多少：**A 76→43%（−33pp）、B 50→25%（−25pp）**，
而 C/D 只掉 6/5.8pp。

⇒ 聊天式语料的"给事实"里**约 1/3 来自固定答复行**（能力/边界声明），**不是查图答案**。
引用这个数时必须说明是哪种语料。

## 3.6 「诚实未知」经得起换问法（§6.503）

A 里 21 条"诚实未知"，换成 3 种问法再问：13 条能答，但来源是 `retrieval` 10 / `frame` 2 / `other` 1，
**`relation` 0 条**——典型答复是语料回声（"我会一直陪你把事情做完"）。

⇒ 换问法只是**绕过诚实护栏**、掉进检索串台；**不是"知识在库里却问不出"**。

**扩到四个语料（§6.504，§6.505 修正）**：未知 A 21/B 22/C 56/D 9 条。按变体拆开：
`+吗` 13 条（真修复，来源 retrieval 9 / frame 4 / **relation 0**）、`+呢` 0 条、
`−吗` **41 条是假象**（去掉"吗"把疑问变陈述，系统把它当事实学进去，回声「记下了：…」）。

⇒ 即使换成正确问法也**换不出知识**；"诚实未知"是真的。

## 4. 已知边界（照实说）

- 比较类（`猫比狗大吗`）**诚实拒绝**；`谁更会飞` 答成"列出会飞的"（答得上但不是原问题）。
- 倒装/被动（`会被猫追的动物是狗吗`）**答不上**（需要论元重排）。
- 长施事里带「的」（`猫被实验室的研究人员认定为动物吗`）**现在能答**（§6.495 修好 `@x` 顺序后 15/16）。
- `retrieval` 串台只在**聊天式输入**（13%）；结构化问句上 0%。
