## 二、逐项证据（命令都可直接跑）

### ① 并发
- `tools/concprobe.c`（默认模式）：4 个脑并行问答 = 串行结果的**逐字节**一致（`tests/suites.txt` 的 `conc`）。
- `--teach` 模式（§6.604）：4 线程各建脑、各教 2 条独有事实、回读自己 + 查别人 ⇒ 不串脑。
- `tests/conc_tsan.sh`：TSan 下 **0 处数据竞争**（默认 + `--teach` 两种模式；
  机器 ASLR 让 TSan 起不来时**显式 SKIP**，不假装通过）。
- 契约写在 `docs/concurrency.md`：**1 线程 = 1 脑**；"多脑各自学"合法，"同脑多线程"不保证。

### ② 查 bug（这一阶段实际修掉的）

### ③ 学习机制（现在的行为）
- **教**：`X 属于 Y` / `我 教 你 ， X 属于 Y` / 带标点 / 两个陈述一句 / 陈述+问句混一句（两件都说）。
- **问**：`X 属于 Y 吗` ⇒ 对/不对/不知道；`你 怎么 知道 X 属于 Y` ⇒ 出处（教学留痕，跨会话）。
- **冲突**：学到与旧值冲突的事实 ⇒ 当场说清 + 问"要改吗"；回「对」⇒ 真撤（复检可见）；
  `::contradict` 给**全图矛盾清单 + 裁决建议**（教学留痕 > 写入序号 > 命中数，都对不上就不表态）。
- **改口**：`不对 ， X 不 属于 Y` ⇒ 改过来；`不对`（对刚给的答案）⇒ 撤回并改口。
- **存续**：`::save` / 重开之后事实与出处都还在；`::learn` 给"这一会话学到了什么"。
- **留痕上限**：只保最近 256 条（`AIP_TEACHMARK_MAX` 可调），超了淘汰最老的（知识不动、只丢出处）。
- **会话级验收**：`tests/e2e_session.sh`（13 项）走完 教→问→出处→改口→冲突→存读→切脑。
- **属性**（§6.623）：`我 教 你 ， 南极 很 冷` ⇒ `南极 --[属性]--> 冷`；`南极 很 冷 吗` ⇒ 对；
  没教过 ⇒ 照实说"图里没记"。
- **指代**（§6.624）：`小明 喜欢 游泳` 之后问 `他 喜欢 什么` ⇒ 指回小明；`他 觉得…` 这类**视角句不换**。
- **亲属**（§6.626）：`小明 是 我 的 表弟` ⇒ `小明 --[亲属]--> 表弟`；`小明 是谁` ⇒ "小明 是 你 的 表弟"。
- **原因**（§6.627/§6.629/§6.630）：`A R B 因为 C` / `因为 C ，A R B` ⇒ 记住原因（**写进存档 v15**）；
  `为什么 A R B` 与 `为什么 X 很 Y` ⇒ "因为 C —— 你 教 我 的（我 没 验 过 对 不 对）"。
  ⚠ 格式抬到 v15：**新二进制写的档，旧二进制读不了**（旧档仍可读）。

## 三、"没有做的" → **现在各有一条最小通路**（第 41–50 轮做的；边界照旧写清）

| 缺口 | 以前 | 现在（最小通路） | 边界 |
|---|---|---|---|
| **原因** | `A R B 因为 C` 整句学不进 | `AI.reasons[16]`，**已进存档（v15）**；因果在前/在后都能学；`为什么 A R B`、`为什么 X 很 Y` 都查原因表，并明说"你 教 我 的（我 没 验 过 对 不 对）" | 16 条有界（满了覆盖最旧）；不验证不推理；属性原因的措辞生硬 |
| **属性/形容词** | `X 很 Y` 掉生成流水线出词串 | `X --[属性]--> Y`（带教学留痕）；`X 很/挺/太 Y 吗` 教过答对、没教照实说 | 不是数值；属性多值（不提示冲突）；程度词归一（丢程度）；不传递 |
| **亲属/身份称谓** | 回聊天模板 / 说没记过名字 | `A 是 我/你/他 的 K` ⇒ `A --[亲属]--> K`；`X 是谁` 答称谓 | 只认五段式；称谓表封闭 16 词；无反向/对偶推理 |
| **代词指代** | `他 喜欢 什么` 完全不接 | **问句里**句首 `他/她` ⇒ 上一句完整主语；**视角句不换** | 只换句首、只换问句；`它` 走旧那套；中间隔句会指错 |

**四条都是"能教进去、能问出来、边界写在回复里"的最小版本，不是理解。**

## 七、结论

**"教一句、记住、追问出处、说不对能改、存盘重开还记得、换个脑不串"—— 这条链能走完，
而且每一步都有套件钉着。**

四条曾经的缺口（原因 / 属性 / 亲属 / 指代）现在各有一条**最小通路**（第 41–52 轮）：
能教进去、能问出来、边界写在回复里；**原因还进了存档（v15）**，重开还在。

**它仍然不是"理解"**：记的是关系边 + 一张会覆盖的 16 条原因表；
- 属性不是数值（不知道多少度、不比较、不传递）；
- 属性多值，不提示冲突（没有温度语义）；
- 亲属没有反向/对偶推理；
- 指代只换句首、只换问句，隔一句会指错；
- 原因不验证、不推理、有界 16 条；
- **格式 v15：新档旧二进制读不了**。

这些边界每一条都写在上面第三节的表里和对应审计（§6.6xx）里，不是"应该没问题"。
