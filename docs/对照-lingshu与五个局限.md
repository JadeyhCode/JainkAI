## 一、那份实现里有什么（与我们相关的部分）

| 模块 | 机制要点（提取出来的判据/阈值） |
|---|---|
| `core/provenance.py` | `Provenance` 10 字段；来源 7 类 / 观测位 8 类 / 工具 9 类**枚举收敛**；强度三档 `strength()`：`verify_methods ∩ {whitebox_code, action_world, human_review}` 才是 strong；硬判据「**声称已验证 ⇒ methods≠none 且 verify_ref 非空**」（不可复现的验证等于没验证）；`is_traceable()`：unknown 来源不可溯源 |
| `world/channel_credibility.py` | **可信度是学出来的**：Beta 后验 `cred=a/(a+b)`，先验 `Beta(2,2)`；每次验证 `n_eff = conf×10×min((1-α)×20, 6)`，强验证 α=0.7（每次 +3）、弱验证 α=0.95（每次 +0.5）；0.3 降权 / 0.15 检修 |
| `world/confirmation.py` | 「确认」是四联判据：全通道 cred ≥0.5 ∧ realized_KL >0.05 ∧ 稳定 ≥5 轮 ∧ 无矛盾；分层 weak/strong/stable；**确认只改状态与标签，不删记录** |
| `core/condition_normalize.py` | 条件规范化三步：域枚举 → **同义词表**替换 → 越界一律 `UNASSERTED`，等价归并判据是 `cond_hash`（canonical JSON 的 sha256 前 16 hex）；域分 **evaluated / asserted**（声明可被求值反驳 → `DEFER_REVIEW`） |
| `core/verdict.py` | **四态判定** `ACCEPT / REJECT / DEFER / BLINDSPOT`，有序短路阶梯，输出只有 `{verdict, reason, 数值}`；**DEFER = 待验，不是否定**；BLINDSPOT = 能力不可判（诚实声明，不伪实现） |
| `core/longterm_gate.py` | 写入分级闸门：`imp = 0.30·novelty + 0.25·trust + 0.15·Δ²D + 0.15·Δ²T + 0.15·mention`；≥0.70 长期层（置**不可遗忘**保护位）、≥0.40 知识层、**<0.40 情境层且快照直接丢弃**；相似度 ≥0.95 → 改写不新建 |
| `world/stable_lease.py` | `stable` 不是终态而是**带 TTL 的租约**：`(t-t_verified) ≥ TTL ∨ conf·e^(−γ·age) < 0.3 → weak`；γ=0.0005、TTL=3600；**降级只作用于状态，不作用于记录** |
| `world/gap_dual.py` | 缺口对偶：`D_task`（图上最小可达距离，空集 → ∞ → BLINDSPOT，可增可减=学习目标）与 `D_meta`（未建模总量，单调不减=认知边界），**两个量纲不允许相互抵消** |
| `core/time_core.py` | **全库唯一时间核**：`X(t)=X∞+(X0−X∞)e^(−γt)`；别的衰减写法（`exp(-t/τ)`、`×(1-factor)`、EMA 保持率）**都算 bug**，由 lint 机械审计 |

**一句话**：它的强项不是算法新，而是**纪律密度**——条件显式、来源可溯、验证分级、
降级不动记录、时间核唯一、判定四态。这些正好对着我们记下来的那几条局限。

## 二、五个局限怎么解决（逐条：借什么 + 我们怎么落 + 代价）

### 局限 1：前提成立只看「注意窗口」（提到过没有）
**借**：他们的「条件成立」是**真判据**，而且分 evaluated/asserted —— 声明的不如求值的硬。
**我们怎么落**（**这一轮已实现前两档**）：

| 档 | 判据 | 状态 |
|---|---|---|
| `mention`（默认） | 前提 token 在当前注意窗口里 | 已有 |
| `activate` | 窗口里没有，但**从窗口出发受限扩散够得着**（深度≤2、能量≥0.25、从权重≥0.3 的焦点出发） | **已实现**：`::premhold activate` / `AIP_PREMHOLD=activate`，optest ㉑ 四项 + features 一项 |
| `verified`（下一轮） | 前提本身**被求值过**（有观测边/能独立推出），对应他们的 evaluated 档 | 设计已定：在 `[前提]` 边旁记一个 `verified` 位（role 字节还有余量，格式不动） |

代价：`activate` 会放宽 R10 的闸门 → 属行为改变，**默认仍关**，跑 `AIP_PREMHOLD=activate sh tests/all.sh` 对照。

### 局限 2：前提说明是「追加」而不是「替换」；`::notepad on` 替掉流水线措辞
**借**：他们的**四态判定**——`DEFER` 的语义正是「待验 ≠ 否定 ≠ 不知道」。
**我们怎么落**（**这一轮已做一半**）：前提没成立时的那句话从
「不过这件事有个前提…」改成 **「待验：这件事有个前提「X」还没成立 —— 不是否定，是还定不了」**（已改，测试同步）。
**下一轮**：把「判定」做成**结构化状态**而不是措辞：`RelationAnswer` 加 `verdict ∈ {ACCEPT, DEFER, BLINDSPOT, REJECT}`，
`::notepad on` 替掉流水线措辞时**把规则名/链式渲染拼回草稿**（`写` 之后 `插入发言` 用 `der_chain_text`），
而不是只说结论。代价：动输出，先 A/B。

### 局限 3：对话触发只认四种说法；写入路由只覆盖关系事实
**借**：`condition_normalize` 的**同义词表 + canonical hash** —— 说法再多，归一之后是一个键。
**我们怎么落**：
1. 触发关键词表加**同义词列**（`加/插/添/塞/放`、`前提/条件/前题`、`回收/清理/扔掉`），
   并把「同一轮里出现多个同义动词」按 canonical 归并（`dialog_trigger_try` 里加一个 `dialog_canon_verb()`）；
2. 触发**事件去重**用 canonical 键（同一句话重复说不会建两次）；
3. 写入路由：把「结构类」写入也纳入（内部对话 `AI_WSRC_INNER`、想象 `AI_WSRC_IMAGINE`），
   但**想象/内部对话本来就该直写**（它们是"想法"，不是知识）——所以这条的正确答案是
   **把"能被路由的写入"列成一张表 + 在 `::safe` 里说明每一类为什么直写/过审**，而不是无脑全路由。
代价：1 轮，低风险（触发是窄集，词表加行）。

### 局限 4：他说的按 `(A,关系,B)` 精确匹配（同义改写对不上）；假设层只看当前视角一层
**借**：他们用 `source + session_id + observation_position` 表达"谁在哪说的"，
用 `multiview` 的多条观测合并同一对象（同类别并进滑动窗），冲突交给四态判定。
**我们怎么落**：
1. **谓词规范化表**（一处）：`以为/认为/觉得 → 以为`，`爱/喜爱 → 喜欢`，`惧怕/害怕 → 怕`；
   `other_belief_find()` 用规范化后的 (A, rid, B) 匹配 → 同义改写能对上；
2. **宾语按类别归一**：他说「猫 属于 家猫」，我问「猫 属于 猫」→ 用现有 `token_is_descendant` 做**双向包含**判定；
3. **他的表加会话/时间**：`OtherModel.bel[i]` 已有结构，旁边加 `first_tick/last_tick/说过的次数`（写进 v9 的
   现有字节区外的新字段会破格式 → 用**图里的 `[时刻:]` 链**代替，或者接受"不持久化时间"）；
4. **多层视角**：`hypo` 层从"单层"改成**栈**（`HypoLayer layers[4]`），查询按栈顶向下逐层求值 —— 这是格式内改动（hypo 不进存档）。
代价：1~2 轮，中风险（改匹配口径会改 `belief.sh`/`hypo_*` 的答案，要 A/B）。

### 局限 5：可信度是启发式；情绪耦合手调；顺序只看首次见到；未解问题文本被截断
**借**：① **通道可信度 Beta 后验**（学出来的）；② **唯一时间核**；③ **TTL 租约**（降级不动记录）；
④ **写入分级闸门**（低价值直接丢弃）。
**我们怎么落**：
1. **可信度改成 Beta 后验**（**这一轮已做一半**）：保留"来源档"作为先验中心
   （基准 Beta(6,2)、观测 Beta(4,4)、推论 Beta(3,7) ≈ 0.75/0.50/0.30），
   每次"命中/被推翻"更新 a/b；`cred = a/(a+b)`。**用一个全局 `chan[]`（按来源档 3~6 个大类）**，
   不按边存 → **格式不动**。
2. **唯一时间核**（**这一轮已做**）：`ai_recency_weight(age)` 一处实现（指数族），
   `assoc_credibility` 只乘它；以后 TTL/租约/新近度都走它。
3. **未解问题文本截断**：`think_ask_name` 的预算从 40 提到 **96 字节**（`[自问:…]` 名字变长，
   仍在 TOKEN 名字上限内），并在恢复时**优先用图里 `[自问:]`→主语那条边**补全主语（不依赖文本解析）。
4. **情绪耦合**：表加两行（疲劳→候选数、舒适→探索偏置），并把参数**写进 `::drive` 的输出**（已有），
   阈值仍手调但**标注"手调"**；真正的"学出来"留给下一轮（需要反馈回路）。
5. **顺序只看首次见到**：加**区间**判据 —— 用 `[时刻:N]` 链给出"谁在谁之前**出现过**"，
   并把"同时出现"和"先后不明"分开（对应他们 `time_window` 与"顺序不入 hash，只入事件序"）。
代价：1 轮（第 1、2 项这轮已落地一半）。

## 五、这一批踩到的两个坑（都写进代码注释）

**① 谓词别名只对"分词器不切开的词"有效。** 别名表加好之后测「喜爱」发现：
分词器把它切成「喜」+「爱」两个已知字 → `rel_id_of("喜爱")` **永远不会被调用**，别名形同虚设。
实测模型里的 token：`害怕` ✓ 有、`拥有` ✓ 有（3 条边）；`喜爱/喜好/惧怕/具有` ✗ 都不是 token。
→ 结论：**多字别名要先是词表里的 token**；表里那几行先留着（等它们进词表就自动生效）。

**② `害怕 → 怕` 这条别名会和 `frames.txt` 抢话。** 帧文件里有一条 `[帧:害怕X吗]`
（问法就是「你 害怕 <X> 吗」）；把它归到核心关系「怕」之后，**关系层会先答**，
帧层那条兜底就再也走不到 —— 被 `tests/hypo_frames.sh` 当场抓住（假设下的帧/检索路径不再被走到）。
这是"归属该给谁"的**设计裁量**，不是能顺手改的事：本轮**选择不动帧层**（不收这条别名），
把冲突记在这里与 `rel.h` 的注释里，留给以后裁。

**③ 一处连带修复**：`n_cached/n_retracted` 从 `Think` 挪到 `AI`（来源档后验要用），
`tools/delibtest.c` 的两处引用同步改了 —— 整包回归才重新变绿（这也是"记账只留一处"的代价与收益）。

## 七、闸门放错地方的教训（这一批最值得记的一条）

「写入分级闸门」先在**用户观测**那条路上实现（`agent_learn_relation` 里），跑出来两个问题：

1. **和铁律冲突**：挡住 `我 厌恶 螺蛳粉` 这种"随口一说"，等于挡住**观测** ——
   而本项目的铁律是「只有观测进图」。观测是知识的**来源**，不该被"重要性"筛掉。
2. **量出来的事实：它根本打不着火**。写了 `tools/wgateprobe.c` 扫全图 167 条关系边：
   `imp` 全部落在 **0.473 ~ 0.605**（中位 0.545），借用来的 0.40 阈值下**一条都不会被拦**，
   0.70 的"长期层"也永远够不到 —— 因为分数量纲由几个近似常量撑起来
   （自模型信任固定 0.5、惊讶 0、不累 1.0），判别力太弱。
   （顺带修了一个真错：`trust` 项一开始拿 `ai_source_posterior(观测档)`，那个被 24 万次训练学习
   撑到 ~1.0，会让闸门**恒定 ≥0.55**；改成自模型量 `inner.predict_accuracy`。）

**改放的位置**：闸门挪到 **AI 自己写知识**那一侧（思维层的**缓存沉淀**）——
用户说的观测永远照收，但它**自己想出来的东西**得够分量才配沉淀成缓存（不够就只留在痕上，
`::delib` 里看得见「写入闸门：这条太轻…先不沉淀」）。默认仍是关。

**留在文档里的结论**：`imp` 这套五分项评分在**我们这个模型**上判别力不足（量纲被常量主导），
要真用它得再找两三个**有方差**的项（比如"与已有知识的重叠度""这条关系被后续观测推翻的概率"）。
现在它的价值是：**位置对了**（管自己写的、不管听来的）、**默认关**、**可测量**（有探针）。

## 九、长轮次继续：让"学出来的可信度"跨重启活下来

**发现的缺陷**：`n_rel_learned / n_revised / n_cached` 这几个计数器**没进存档**
（格式不动是硬约束）→ 「改口越多观测档越低」这件事**一重启就归零**，
等于**假的学习**。

**修法**（和 emb / idf / 槽类同一个路子：**从最终的图现算**，不另存一份）：

| 证据 | 从图里怎么数 |
|---|---|
| 现场学到的关系事实 | 带关系位且 **`role ≠ 基准`** 的边（基准是装载 `relations.txt` 时打上的标） |
| 改口次数 | `[修正:…]` 标记节点的个数（改口时经安全内核落下的普通 token） |
| 现在还挂着的缓存 | `role == ASSOC_ROLE_DERIVED` 的边数 |

`ai_recount_evidence()` 在 `ai_load_file` 收尾调用一次。

实测：现场学两条关系 → `::save` → **另一个进程** `::load` → `::stats` 报
「现场学到 2 条」「来源档可信度：观测 **0.60**（不是先验 0.50）」✓

**局限照实说**：被**撤销**的缓存数（`n_retracted`）恢复不了 —— 撤掉的东西图里没有痕迹，
所以推论档的后验在重载后会略偏乐观。这一条写进了函数注释。

**顺带补的呈现**：`::stats` 现在直接列出「来源档可信度（后验）：基准/观测/推论」；
`::why` 报「依据租约：稳定/减弱/过期」；`::src` 的"他说的"在精确匹配失败后会**按类别**再找一遍
（`猫` vs `家猫` 这类，只影响呈现，不改判定）。

## 十一、开关对照表 + "成对开关"也能测

新增 `tests/switches_ab.sh`：把每个"默认关"的开关**单独跑一遍整包**，出"基线 vs 打开"对照表。
第一次跑完发现两件事：

1. **单独跑都不动基线**（wgate / premhold-verified / route / affect / notepad-on / patch-note 全 PASS）；
2. 但**成对**才有意义：`AIP_PATCH=记事本 AIP_NOTEPAD=on`（AI 自己写草稿并决定发送时机）
   是**已知会改输出**的一组 —— 第一次成对跑，**9 套红了**
   （relations / hypothesis / logic4 / belief / hypo_frames / prerequisite / consolidate / revision / tokenop）。
   原因是那 9 套的断言看的是**流水线措辞**，而 notepad-on 就是要替掉它。
3. 按项目一贯的纪律修：**断言自己钉住模式** —— 那 9 套的 `run()` 里加一行 `::notepad off`，
   这样环境变量强制打开时，它们测的仍是自己该测的东西；
   "notepad on 会怎样"由 `tests/selfmod.sh` §9 **专门测**（那儿有 7 项）。

顺带修好了脚本本身的一个坑：开关表原来用**空格**分隔条目，于是"成对"的那条被拆成两个开关，
表里出现一行**看着像测过、其实没测**的记录（跑出来"没变"）。改成**一行一个开关**
（值里可以带空格），并加了 `ONLY=<名字>` 只跑一个。这条本身就是"测量工具必须自己可信"的例子。
