## 4a. 词级同义（`[syn]`）能买到什么（§6.365）

- `[syn] 疲惫=累` / `疲倦` / `疲劳` / `最爱=最喜欢` / `一般=平时` / `日常=平时` 六行
  ⇒ 换说法的自我描述问题**兜底 48%→22%**（27 条盲探针，11→18 条给事实）。**不改代码。**
- 代价：**复读率 19%→44%**（能答的题多了，但答复多是语料原句）⇒ 买到"听懂"，不是"会生成"。
- 坑：`[syn]` 是**子串替换**。`爱=喜欢` 会把 `喜爱` 拆开（套件当场红）；
  `寂寞=孤独` 是死行（目标词自己也不认识）；`恐惧=怕` 没有改善（问 `怕` 本来就答那句绕的）。
- **输入带字间空格时同义词表失效**（`你 疲 惫 吗` 匹配不到 `疲惫`）；探针要写真人写法（不空格）。

## 4z185. `::brain drop N`：关掉一个脑 + 槽位复用（§6.578）

- `drop N` 释放并置空槽位；当前那个**明确拒绝**；`new` 优先填空槽；末尾空洞自动收缩。
- 实测：drop #1 后 list 少一个、`new` 填回 `* #1`；drop 当前脑被拒。
- 判据：tokenop **311 项**、整包 **49/49**、`probematrix` diff 为空、selfcheck/asan(90) 全 PASS；
  另用 ASan 手工跑 `new/new/drop/new/drop`：无泄漏/无 UAF。
- 边界：不写盘（要留先 save）；编号不重排；单线程。

## 4z183. `::parts verify` 自检 + delta 自动挂覆盖层（§6.576）
- `aip_parts_verify`：有备份 / 还没写 delta / **stale（段条数≠内存条数，必须 0）** / 孤儿索引。

## 4z201. 阶段②补覆盖：`::op` 进随机模板，逮到"存盘后读不回来"（§6.598）
- 缺口：§6.584 的 `bughunt` 随机模板没打 `::op` 原语（当时写明是已知缺口）。补进 7 条
  （加前提/加反前提/中间插词/建过程/加步骤/加条件/回收临时）之后，**存读往返当场红**。
- 根因（两层）：① 写盘跳过临时符号节点 `[临:…]` ⇒ id 缺口，而读盘有 `t->id != id` 硬校验
  ⇒ **整份存档静默读不回来**；② 第一版修法"补记录"又没把它算进头里的 `n_tok`、且对临时节点
  "声明 0 条边却照写边记录" ⇒ 读盘错位（`self/good/bad/unknowing` 读成非法 id）。
- 修（`model_io.h` 三处）：头计数包含临时节点；临时节点写记录（名字照写、`n_saved_edges=0`、
  落盘强制 `is_garbage=1`）；边循环加 `&& !is_temp`。
- 严重性：**数据丢失级** —— 跑过 `::op 加前提` 再 `::save`，存档就覆盖成读不回来的文件。
- 判据：`bughunt`（含 `::op`）种子 1/7/42 × 400 步全绿、ASan 3/11/99 × 300 步全绿；
  `tokenop` **372 项**（+3：op 后能存盘 / 读得回来 / 反查表自洽）；整包 **57/57**、asan(92) 干净。
- 边界：临时符号节点会被**保存成垃圾占位**（名字占位）⇒ 存读不再"逐字节等价"，换来 id 连续。

## 4z198. 「你教我的」跨会话认得出：教学留痕（§6.595）

## 4z197. `::askconflict off` + 一次完整会话的验收（§6.594）
- `::askconflict on|off`（`AIP_ASKCONFLICT=0`）：学到冲突事实时"问不问要不要改"可关。
  关掉的只是**追问**——冲突照样说清、给显式撤法（`X 不 R Y`），只是不挂待确认（回「对」不会撤）。
  措辞 `[say] 冲突.不问`；帮助文本进 `::help`（`asan_check` 命令面 90→91）。
- `learnprobe` **G 组（15 项）**：按真人顺序走完整会话 —— 教学意图 → 问 → 出处 → 上位继承 →
  数量事实（学/有没有/几个）→ 冲突 → 一个字改口 → 旧值变假 → `不 对 ，X` → 「我刚才教了什么」→
  存盘/读回 → 不变式。这是"在交互中学习可用"的**端到端证据**。
- 坑：字符串手术把 `else if` 复制成空分支（`resp0` 未初始化 ⇒ 垃圾字节）；同一次手术删掉了
  `[修正:…]` 标记块（10 项红）⇒ 最后**恢复 HEAD 原样 + 只加门控**；探针要自己调
  `aip_shell_mirror_lead`（`[lead]` 要落成外壳词），但**只在真模型组**做（空脑子上镜像会红 12 项）；
  `selfcheck ⑤` 抓到断言串撞 `::help` ⇒ 换成帮助里没有的半句。
- 判据：learnprobe **61 项**、tokenop **361 项**、整包 **57/57**、`probematrix` diff 为空、asan(91) 干净。
- 边界：`ask_conflict` 会话内有效（不进存档）；G 组是脚本化固定会话；冲突不会自己消失；
  来源写进边、遗忘曲线仍未做。

## 4z196. 教学意图 + 「我刚才教了什么」（§6.593）
- 现象：`我 教 你 麒麟 属于 神兽` 听不懂；`记 一下 麒麟 会 飞` 被错记成**过程**
  （`[过程:一下麒麟会飞]`，事实没学）；`请 记住 …` 也不学；学了一堆却问不出"教了什么"。
- 修：教学意图就是**引导语** —— 加 5 行 `[lead]`（我 教 你 / 我 教 给 你 / 我 告诉 你 / 请 记住 / 记 一下），
  复用既有的"数据桶→图外壳"剥离层（还能叠在 `难道…` 后面）。另加 `[say] 回顾.教了/回顾.没教` +
  `agent_taught_review()`：从本会话修改账里列最近 4 条关系事实 + 总条数。
- **试过并撤掉**：代码级前缀剥离 + 过程入口守卫（"剩下有核心关系词就别当过程名"）——
  A/B 掉 5 条（blind4/blind5/pert）。原因是那几条 holdout 扰动句**以前靠"被错记成过程"通过**的
  （期望答复含「记下 了」，过程答复也含）。改回 `[lead]` 数据行后 holdout 全回基线。
- 判据：`tokenop` **357 项**（镜像日志那条断言改为**从 patterns.txt 现数**，不再写死 55）、
  整包 **57/57**、`probematrix` diff 为空、holdout 448/131/215/13 全回基线、asan(90) 干净。
- 边界：只认带空格的教学意图；回顾只看本会话的账（256 条环形、不进存档）；只列关系事实；
  触发是子串判据（"教了/教过/教会" + "什么/啥"）。

## 4z195. 数量事实（§6.592）
- 现象：`麒麟 有 三 个 角` 被检索抢答（`个` 在虚词表 ⇒ natcoin 拒）；`猫 有 几 条 腿` 明明记了「四条腿」
  却答"没记数目"；`A 有 三个角 ⇒ A 有 角` 这条蕴含没落地。
- 修：natcoin 放行"数词+量词+名词"（新增 `rel_is_measure_extra` 度量词表）；`agent_quantity_lookup()`
  从 `有` 边上的合成宾语里读数目（`[say] 数目.已知`）；`token_has_attr_quantity()`（rel.h）接进求解器
  直接事实层、`derive.h` 的 `DER_FACT` 复核、`agent_has_attr`。
- 四个坑：`kn_pos` 把它当缓存 ⇒ DER_KNOWN 缺口；验证器要同一条判据；复核模式要同一条判据；

## 4m. 模态词（§6.377）

- `可能/也许/或许/大概`：**不删词、不当事实学**；问句答"概率我不会算"（附一句"要问事实就直说"），
  陈述答"带也许的说法我记不了"。基线 10 条兜底 4→0，模态陈述被学 1→0。
- `一定/应该` 进 `[fill]`（断言/推断语气，删掉不改真假）。
- 已知信息损失：`猫也许属于动物吗` 不再答"对"，只答"不会算概率"。

## 4l. 第二组填充与两个小桶的核实（§6.376）

- 第二组 `[fill]`：`根本/简直/竟然/居然/毕竟/想必/显然` ⇒ 盲探针兜底 **9/10 → 1/10**。
- **`大概/可能` 故意不收**：它们是猜测语气，删掉会把"可能会飞吗"答成"不对"（答错问题）。
  代价：`猫可能会飞吗` 仍是兜底，`猫大概会飞吗` 答复别扭——已知坏答复，需要模态层才能修。
- 核实：`[slot]`（`哪一类`）与 `[confuse]`（没听懂说法）**都承重**（消融后各有一条问句掉兜底）。

## 4k. 副词填充 `[fill]`（§6.375）

- 新数据桶：`真的/其实/确实/实际上/到底/究竟` —— 出现在句中任何位置就整段删（按分词写）。
- 盲探针 `tests/filler_para.txt`（10 条）兜底 **7 → 0**；带填充的陈述仍当教学（对照没误清）。
- 护栏：删完至少剩 2 个词（`真的` 单独一句不会被删空）；新桶进加载自检（1:1 计数）。
- 顺带结论：`啊/呀/嘛` 和 `谢谢，…` 那两种**不是** bug（没 吗 就是陈述），已在审计里写明。

## 4j. 提问式引导语（§6.374）

- `[lead] 请问?` 尾部 `?` = **问句引导语**，由数据决定（代码里不再写死标记表）。
  剥掉后余句没有 吗/呢/?! ⇒ 补一个「吗」⇒ 不会被当陈述学进去。
- 基线：11 条探针里 **7 条**提问式引导语被当陈述、触发改口（把「猫不会飞」写成「猫会飞」）；现在 **0**。
- 顺带修：引导语**最长匹配**（`请问一下` 先于 `请问`），否则会造出「一下猫」这种词。
- 空白：`麻烦` 只在数据里标了 `?`（没进代码安全网）；`诶/那个` 是呼语，故意不标（避免挡掉正常教学）。

## 4i. 反问标记的安全（§6.373）

- **反问句绝不能当陈述学**：`难不成猫会飞`（没有 吗）以前被 lead 剥成"猫会飞"⇒ 触发改口，
  把「猫不会飞」写成「猫会飞」。现在剥掉反问标记后**补一个 吗**，并把这些标记列进问句词表。
- 探针 `tests/rhet2_para.txt`（11 条）兜底 **5→0**；`rhet2_para2.txt`（6 条，**事后补的、不是盲的**）3→0。
- 附带修：`岂` 进词表（不然会并成 `猫岂` 造出垃圾实体）。
- 分层结论（套件里有对照）：**"答得出"靠数据行，"不被学进去"靠代码守卫**。

## 4h. 反问/强调问（§6.372）

## 4g. 数据层自检（§6.371）

- 启动时默认核对"每个桶文件行数 vs 进表行数"，不一致就打 ⚠（`shape` 除外，它自动生成变体）。
- 第 44 套 `tests/patlong.sh` 固定三件事：~500 字节长行要能加载命中、~731 字节要喊「关键词串太长」、
  仓库自带数据不许触发警告。旧二进制跑这套 ⇒ 3 条 FAIL。

## 4f. 时间/地点/比较/数量四族（§6.370）

- 盲探针 `tests/fam_para.txt`（17 条）：兜底 **47% → 0**；换词换实体的第二组 12 条：**58% → 0**。
- 做法：末级兜底认"数量/年龄/比较"三种结构，只说"没记数目/没记年龄/不会比较"；
  时间词族补词（`后天/前天/今晚/早`）走既有的"没有时钟"答复。**都不假装会**。
- 数量那条会顺一层 `属于` 查：`猫有几条腿` 答得出"图里只记了猫有腿，没记数目"。
- ⚠ 顺带发现：`[reply]` 关键词串有 **128 字节**静默上限（超了整行被丢）；已放到 512 并加 ⚠ 警告。

## 4e. "听懂了但不知道"（§6.369）

- 两个实体 + 一个已知关系 + 图里没有这条边 ⇒ 答「我 不 确定 A R 不 R B —— 图里 没 记 过」，
  不再答「这个我 不 太 懂」（后者等于说"我没听懂"，是假的）。12 条探针 7 变 5 不变。
- **放在最后兜底那一步**，不是关系求解器里：第一版放求解器里会抢在类比/检索/帧之前返回，
  语料样本 D 的"给事实"从 50 掉到 39（11 条被截胡）。这是分层问题，记在这里防再犯。
- 只在实体、关系词都在池里时才这么说；`猫 在 北京 吗`（北京不在池里）仍掉兜底。

## 4d. 知识类换说法：8 条形状行买到了什么（§6.368）

- 盲探针 `tests/know_para.txt` 19 条：兜底 **42% → 0**；换词换实体的第二组 7 条：兜底 **100% → 14%**。
- 8 行都是**固定搭配 → 已有答案路径**（`哪类/哪种/归哪一类`、`V得起来`、`长X`、`身上有X`、
  `是…的` 话题前置、`算…吧`），没有一行是针对具体实体写的。
- 没修好的：`猫是狗吃的吗`（改写正确，但 `狗吃猫吗` 本身是知识缺口——两个已知实体 + 未知关系
  没有"不确定"出口）。这是知识层的事，不是说法层。

## 4c. 第二人称（§6.366/§6.367）

- `你 R 什么` 这类开放问句**不再**当"图里的实体"查（以前答「我 记 的 是 ： 你 怕 什么 …」，像复述问题）；
  现在交给下游：有自我描述就答，没有就老实兜底。12 条探针里回声 5→0（2 条变好、3 条变诚实兜底）。
- **不能**把 `你` 换成图里的 `我` 去查：图里只有一个 `我` 节点，存的是**用户**的事实，
  换过去会让机器人把用户的喜好当成自己的（`你 喜欢 什么` 答出用户喜欢的东西）。
- **是非问要换视角（§6.367）**：`你 爱 我 吗` 以前答"我不知道你爱不爱我"（把你当成用户），
  现在答"我不知道我爱不爱你"。主语是第二人称才换，第三人称（`猫 喜欢 你 吗`）不动。
  还剩下的同类错位在**帧模板**层（`你 有 毛 吗`），改帧要重训模型。

## 4b. 数据桶的**工装纪律**（§6.352）

- 任何桶到上限都必须**打 ⚠ 并丢弃**（`[shape]`/`[reply]`/其余桶现在都会喊）；
- `sh tests/patcount.sh`（已进 42 套）把"文件行数 vs 加载数"钉住，**对不上就红**；
- 这条是五次"桶满了静默丢弃"换来的（§6.304/§6.322/§6.351）。

## 5. 诚实的三条警告

1. **自写留出集的 98.3% 不能外推**；盲测基线 27% 才是"没见过的说法"的起点。
2. 盲测的**现状 87.3% 是"补过壳之后"**的分数——补壳本身用的是同一批盲测暴露的信息，
   所以它也不是"下一次换新包装还能到 87%"的保证（blind2→blind3 就掉了 8 个点）。
3. 所有盲测都是**我用变换族自动生成**的，不是真实用户语料；真实语料的分布没人量过。
4. **"不是兜底"不等于"答得好"**：语料样本的复读率 A 9% / B 14% / C 6% / **D 39%**（§6.364）。
   D 的"给事实 78%"里有 25% 是把语料原句背出来当答案——关于自己的问题（`你 累 吗`）背原文
   在语义上不算错，但那是**记忆**不是**泛化**；另有 4/100 是真错答（`狗 是谁 => 我觉得它们比人单纯`，
   问身份答感想，检索形态问题）。看分数必须同时看复读率。
