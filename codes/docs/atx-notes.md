# `@x` 可变长度填充：用法与四条坑

`@x` 是 `[shape]` 里的**可变长度填充**记号：加载时展开成"1~12 个 token 的任意填充"，
用重复的 `$5` 表示（`$5` 只出现在 lhs，rhs 不引用它，所以不影响改写结果）。

```
[shape] @x 的 $1@k $2@r $3 吗 = $1 $2 $3 吗      # 被称为动物的猫会飞吗 ⇒ 猫 会 飞 吗
```

一条 `@x` 会在加载时变成 12 条（占 `AIP_SHAPE_MAX`），别滥用。

## 四条坑（都踩过）

1. **插入位置**（§6.475 / §6.481 / §6.482，踩了三次）
   展开代码必须放在 shape 分支**最后一个 `continue;` 之前**。
   分支里有"超上限就丢"的早退 `continue`，放它前面 ⇒ **整行被跳过**（`shape=0`）；
   放在分支右括号前 ⇒ 被 `continue` 抢先，**成为死代码**（一条都不展开）。
2. **`@k` 需要词池**（§6.482）
   `$3@k` 要求该 token 已在图里；在 `ai_new()` 没有模型的复现器里**永远不成立**。
   写 `$3`（不要求已知）更稳；真实系统里有模型，两者都能过。
3. **行数 ×12**（§6.482）
   一条 `@x` = 12 条，`patcount` ⑧ 的 `shape=已用/1024` 会立刻涨一截；别在 `@x` 上再套 `@x`。
4. **必须跑在"变体生成"之前**（§6.495，坑了三次才定位）
   加载器存完一行会**立刻生成"逐字拆开"的变体**并推进 `g_shape_n`。若 `@x` 展开放在变体之后，
   它读到的 `g_shape_l[g_shape_n-1]` **已经是变体行**（`属 于`），原始行（`属于`）永远不被展开。
   ⇒ 展开块要放在 **"存行之后、`if (!ai) continue;` 之前"**。
   （修好后：genprobe18 长施事 11/16 → **15/16**，而 blind4 等量尺一动不动。）

## 最小复现方法（省时间的关键）

不要在仓库里"改一处、跑一条输入"。把 `*.h` 复制到 `/tmp/exp`，写一个 30 行的 `t.c`：

```c
#include "ai.h"
#include "agent.h"
int main(void){ AI *ai=ai_new(); aip_patterns_load(ai);
  printf("total=%zu\n", g_shape_n);
  for (size_t i=0;i<g_shape_n;i++) if (strstr(g_shape_l[i],"$5 $5")) printf("%s\n", g_shape_l[i]);
  char out[192]; int ok=aip_shape_rewrite(ai,"被称为动物的猫会飞吗",out,sizeof out);
  printf("rewrite(%d): %s\n", ok, ok?out:"(no)"); return 0; }
```

- 能在**几秒内**看清"行有没有展开、展开成什么、匹不匹配"；
- 注意：那里没有 `model.bin`，`@k` 一律不成立（见坑 2），要么补一个词池、要么把 `@k` 换成裸槽。

## 什么时候值得用 `@x`

- 修饰语/施事**长度不定**、而**前后缀固定**时（`@x 的 X R Y 吗`、`X 被 @x 属于 Y 吗`）；
- **不要**用它表达"语序重排"（倒装）——那需要论元重排，`@x` 只会丢掉信息。
