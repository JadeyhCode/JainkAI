# 学习机制验收状态（第 40 轮汇总；每条都指向可复现的证据）

> 这份文件回答一个问题：**"在交互中学习"现在到底能用了吗？** 能用在哪、不能用在哪。
> 证据都是可以当场跑的命令，不写"我记得"。

## 一、总判

| 目标 | 状态 | 一句话 |
|---|---|---|
| ① 并发 | ✅ | 4 线程各自建脑、各自问答/各自学习，**TSan 0 竞争**，答案与串行逐字节一致 |
| ② 查 bug | ✅（持续） | 随机会话 + 命令面随机会话逮到 3 个**真** bug（存盘读不回 / parts UAF 崩溃 / 标点把事实学成"主语是逗号"） |
| ③ 新旧知识冲突 + 学习可用 | ✅（有明确边界） | 教→问→出处→冲突→裁决→撤销→存读→切脑 全链路可用；**原因/属性/亲属称谓**没有学习通路（会照实说学不进） |

## 二、逐项证据（命令都可直接跑）

### ① 并发
- `tools/concprobe.c`（默认模式）：4 个脑并行问答 = 串行结果的**逐字节**一致（`tests/suites.txt` 的 `conc`）。
- `--teach` 模式（§6.604）：4 线程各建脑、各教 2 条独有事实、回读自己 + 查别人 ⇒ 不串脑。
- `tests/conc_tsan.sh`：TSan 下 **0 处数据竞争**（默认 + `--teach` 两种模式；
  机器 ASLR 让 TSan 起不来时**显式 SKIP**，不假装通过）。
- 契约写在 `docs/concurrency.md`：**1 线程 = 1 脑**；"多脑各自学"合法，"同脑多线程"不保证。

### ② 查 bug（这一阶段实际修掉的）
| bug | 症状 | 怎么逮到的 |
|---|---|---|
| 存盘读不回（§6.598） | 跑过 `::op 加前提` 再 `::save`，存档**静默**变成读不回来的文件（数据丢失级） | `bughunt` 随机会话接进 `::op` 原语 |
| parts UAF 崩溃（§6.600） | `::parts save` → `::load` → `::parts attach` ⇒ **SIGSEGV** | 新套件 `cmdfuzz`（命令面随机会话） |
| 标点学出脏事实（§6.605/§6.614） | `麒麟，属于 神兽` 学不进；`我 教 你 ， 企鹅 住 在 南极` 学成「**，** 在 南极」 | 写"真实用户会话"剧本 + 自己当用户 |

### ③ 学习机制（现在的行为）
- **教**：`X 属于 Y` / `我 教 你 ， X 属于 Y` / 带标点 / 两个陈述一句 / 陈述+问句混一句（两件都说）。
- **问**：`X 属于 Y 吗` ⇒ 对/不对/不知道；`你 怎么 知道 X 属于 Y` ⇒ 出处（教学留痕，跨会话）。
- **冲突**：学到与旧值冲突的事实 ⇒ 当场说清 + 问"要改吗"；回「对」⇒ 真撤（复检可见）；
  `::contradict` 给**全图矛盾清单 + 裁决建议**（教学留痕 > 写入序号 > 命中数，都对不上就不表态）。
- **改口**：`不对 ， X 不 属于 Y` ⇒ 改过来；`不对`（对刚给的答案）⇒ 撤回并改口。
- **存续**：`::save` / 重开之后事实与出处都还在；`::learn` 给"这一会话学到了什么"。
- **留痕上限**：只保最近 256 条（`AIP_TEACHMARK_MAX` 可调），超了淘汰最老的（知识不动、只丢出处）。
- **会话级验收**：`tests/e2e_session.sh`（13 项）走完 教→问→出处→改口→冲突→存读→切脑。

## 三、**没有**做的（照实说）

> 下面这几条是**第 40 轮"第二次自己当用户"**逐条实测出来的（人物/亲属域），不是推测：
>
> ```
> 小明 是 我 的 表弟      → 我 是 你 的 朋友            （没学，回了句聊天模板）
> 我 的 表弟 叫 小明      → 估计，这个我 不 太 懂       （没学）
> 小明 叫 小明            → 记下 了 ： 小 明 叫小明     （学歪了：主语没合并）
> 小明 是 谁              → 我 不知道 小明 是 谁 —— 图里没记过名字（不编）  （如实，因为上面没学进去）
> 他 喜欢 什么            → 我 记 的 是 ： 他 喜欢 什么 ， 图里 没 记 过    （代词不消解）
> ```
> 对照：`小明 是 学生` ⇒ 学成 `小明 属于 学生` ✓；`我 的 名字 是 小明` ⇒ 学成 `我 叫 小明` ✓。

| 缺口 | 现在的行为 | 要做得动什么 |
|---|---|---|
| **原因**（`因为…`） | 图里没有"因为"边；`为什么 A 住 在 B` 只说"只记了在哪、没记原因" | 新关系类型 + 因果推理 |
| **属性/形容词**（`X 很 冷`） | 带引导语时照实说"属性我现在学不进"；不带引导语走聊天 | 属性槽 + 冷热数值/程度 |
| **亲属/身份称谓**（`小明 是 我 的 表弟` / `我 的 表弟 叫 小明`） | 学不进（`小明 是 学生` 这种能学成 `属于`） | 亲属关系类型 + 代词消解 |
| **代词指代**（`他 喜欢 什么`） | 不回指上一句的主语（"我记的是：他 喜欢 什么…") | 指代消解到图里最近的主语 |
| 留痕淘汰是 **FIFO** | 老事实会"丢出处"（知识还在） | 重要性加权 |
| `holdout` 只能判"出现某词" | `::askconflict off` 只能测正面行为 | 判"没出现"的新量法 |

## 四、怎么复现

```sh
sh tests/all.sh                 # 60 套（约 100s）
sh tests/e2e_session.sh         # 一段真实会话（13 项）
sh tests/cmdfuzz.sh 20 60       # 命令面随机（更狠）
sh tests/codetry.sh             # 真机跑 gcc 闭环（8 项）
sh tools/probematrix.sh         # A/B 矩阵 31 行

```

## 五、结论

**"教一句、记住、追问出处、说不对能改、存盘重开还记得、换个脑不串"—— 这条链现在能走完，
而且每一步都有套件钉着。** 没有通路的东西（原因/属性/亲属）**会照实说学不进去**，
不会假装懂，也不会吐词串。

离"像人一样学"还很远：它记的是**关系边**，不理解语义；没有因果、没有属性、没有指代消解。
这一节的每一条都是**已知**的，不是"应该没问题"。
