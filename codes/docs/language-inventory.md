## 3. **不搬**的（不是语言件）

- 极性/否定判据的词集合（`不/没/没有` 这类是**逻辑常量**，进数据只会让"否定"变成可配的东西，风险大于收益）；
- 疑问句分句/关系解析的算法分支；
- 存档格式、预算、上限这类参数（按项目规矩留在 `#define` 参数区）。

## 4. 每块的验收口径（固定，别再发明）

1. **先写用例**（`tokenop` / `bucketload` 各补一条"改数据就变"）；
2. `45/45` + `selfcheck` PASS + `asan_check` 干净 + `patcount` 桶计数对得上；
3. **新旧 A/B**：`git worktree` 拉旧代码 + 旧数据，各跑 `probematrix`，**28 行 diff 为空**；
4. 单桶消融能证明"数据在承重"（`AIP_NODATA=<桶>` 答复变）；
5. 证不出正例就回退，负结果写进审计。

⚠ **两个量尺不能同时跑**（`holdout.sh` 曾把日志写死 `/tmp/holdout_one.log`，§6.530 已修，仍别并行）。
