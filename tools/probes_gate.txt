# tools/probes_gate.txt — Gate B（帧读关联链产物）的 A/B 探针
#
# 选句原则：**槽位取值不在 frames.txt 白名单里，但这个词在模型图里存在**。
# 这才是 Gate B 的适用面 —— 白名单里的词走 Gate A，跟这个开关无关；
# 图里根本没有的词（火锅/火车/钢琴）谁也救不了，Token 都不存在。
# 每句后面注释写清算的是哪个帧、哪个槽位、期望什么。

# —— 恐惧类槽位：怕 <X> 吗。白名单 FEAR 是 黑/孤单/失败/…，没 危险/动物 ——
你怕危险吗
你怕动物吗
你怕老师吗
# —— 对象类槽位：知道 <X> 吗。白名单 24 个里没 动物/老师/天气 ——
你知道动物吗
你知道老师吗
你知道天气吗
# —— 活动类槽位：你 <X> 吗（白名单是 吃/喝/看/听/说/想/学/玩…）——
你在学画画吗
你喜欢安静吗
你觉得天气怎么样
# —— 对照：这些词都在白名单里，两边必须**完全一样**（走 Gate A）——
你喜欢雪吗
你怕黑吗
你知道量子吗
你想学画画吗
# —— 反面：跨度规则不许把「支持 我」整段吞进槽位。
#    曾经答成「我 想 学 支持 我」——这是本模块最典型的病句。
你会支持我吗
# —— 反面：虚词门。『那么』的分布分数 56，比很多实词还高，
#    没有虚词表就会被当成好填充，答出「我 喜欢 那么」。
你喜欢那么吗
