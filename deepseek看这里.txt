## 一、代码层面真的实现了的

### 1. 关联记忆

- **Hebbian 学习**：`token_observe_pair` —— 一起出现的 Token 建边
- **强化**：`hits++` —— 反复出现边越强
- **衰减**：`token_decay_hits` —— 不用的边变弱
- **遗忘**：`mem_state` 四档（ACTIVE/FADING/DORMANT/FORGOTTEN），概率升级
- **复活**：`token_touch` —— 用过就回 ACTIVE
- **重排**：`token_consolidate` —— 按 hits 排序

这些**都在跑**，你 `seed_full.txt` 训练后图里有 2000+ 边就是证据。

### 2. 联想生成

- **扩散激活**：`token_activate` —— 能量沿边扩散
- **加权随机游走**：`ai_pick_next_ex` —— 从边里按权重选下一条
- **能量衰减**：每步 `energy *= decay`
- **多候选选优**：`ai_plan_and_act` —— 生成 N 个，按效价打分选最好

这些**在跑**。你看到"你好→好朋友一类"就是它在图上走了三步。

### 3. 语境匹配

- **必需语境**：`subs[]` —— 全部满足才匹配
- **否定语境**：`subs_not[]` —— 任何出现就失败
- **类别继承**：`is_category` + `parent` —— 类别匹配任何后代

代码实现了，但**当前语料没怎么用**。

### 4. VSA 结构表示

- **绑定/解绑/捆绑**：`vsa_bind` / `vsa_unbind` / `vsa_bundle`
- **视角树绑定**：`vsa_bind_perspective`
- **检索**：`pool_query_vsa` 按余弦相似度找 Token

代码实现了，**当前语料没用**（因为语料是符号共现，不是 VSA 结构）。

### 5. 元认知

- **置信度**：`ai_confidence` 五信号合成
- **知道感**：`ai_metacog` 合成综合状态
- **表达模式**：七档（CONFIDENT/HEDGE/TENTATIVE/UNCERTAIN/LOST/CURIOUS/SILENT）
- **空缺感**：`token_gap` + `pool_unknowing`

**在跑**。你看到"感觉，啊"就是置信度低时的 TENTATIVE 表达。

### 6. 内生状态

- **comfort / arousal / fatigue**：内部状态变量
- **预测编码**：`ai_learn_pair` 预测错就削弱
- **设定点**：`ai_exploration_bias` 根据舒适度调探索率
- **自我模型**：`ai_self_update` 状态驱动"我→好/坏"

**在跑**。只是状态变化慢，短对话看不出来。

### 7. 因果 + 反事实

- **因果边**：`[因果]` 语境下的边
- **反事实学习**：`ai_learn_counterfactual` 对比"考虑过但没做"
- **信用分配**：`ai_credit_from_feedback` 从反馈反向削弱路径

**在跑**，但需要**用户给反馈**（说"不对"）才触发。

### 8. 时间 + 他者

- **时间线**：`ai_timeline_advance` 每轮建 `[时刻:N]`
- **时间链**：`next_in_time` 串联

**在跑**，但需要**多轮对话**才显形。

### 9. 睡眠 + 巩固

### 10. 持久化

## 二、理论上能但当前语料/配置没激活的

### 1. 结构化的语义关系

当前语料是"共现"，没有用 `[前关联]`。所以图里是 `猫→动物` 这种**无标签**边，而不是 `猫 --[属于]--> 动物`。

**能激活**：重写语料 + 改 `agent_step` 传 ctx。

### 2. VSA 类比推理

`ai_analogy` 代码在，但池里没有绑定结构的 Token，所以从来没被调过。

**能激活**：用 `[原语:绑定]` / `[原语:嵌套]` 写几条结构化语料。

### 3. 多视角推理

`perspective_enter` / `[原语:视角]` / `[原语:认为]` 都在，但语料里 `[原语:认为]` 用得少，且生成时没启用视角栈。

**能激活**：加视角相关语料 + 在 `agent_step` 里处理 `[原语:视角]`。

### 4. 想象 / 内部对话 / 叙事

- `ai_imagine`：随机绑定两个焦点 Token
- `ai_inner_dialogue`：焦点环互激活
- `ai_narrate`：从时间线生成"我最近在想..."

代码都在，触发频率低（`imagine_rate = 0.03`、`narrate_every = 500`），短对话看不见。

**能激活**：调高频率，跑几千轮。

### 5. 抽象形成

`ai_form_abstractions` 需要两个 Token Jaccard 相似度 ≥ 70% 才建类别。当前语料 Token 关联太稀疏，很难触发。

**能激活**：加大语料密度，或降低阈值到 50%。

### 6. 自我叙事 + 概念漂移

- `ai_narrate` 每 500 轮一次
- `ai_drift_sample` 每 200 轮一次

短对话根本到不了。跑 1000+ 轮才看得见。

### 7. 因果推理

需要有"我做了什么 → 世界变了"的循环。单机对话不产生因果，除非加**动作接口**（比如调用外部程序）。

## 三、当前跑起来实际表现的边界

| 能力 | 现在能到什么程度 | 瓶颈 |
|---|---|---|
| 记忆 | 记住 8000 句的共现 | 语料格式 bug 导致边建错 |
| 生成 | 3~5 个词的短语 | 语料稀疏、衰减快 |
| 元认知 | 知道自己不确定 | 置信度阈值偏严 |
| 学习 | 每轮都在学，hits 累积 | 自举退化风险 |
| 遗忘 | 长期不用的边会淡化 | 短对话看不见 |

**核心瓶颈不在代码，在语料**：

1. **`X Y Z 连接` 只建 `Y→Z`** —— 大量边建错了
2. **没有关系标签** —— 边是纯共现，没有语义
3. **Token 太稀疏** —— 788 个 Token 对应 2000 条边，平均每个 Token 只出 2.5 条边
