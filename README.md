# JainkAI

**版本：v0.01**（`ai.h` 的 `AIP_VERSION` 是唯一出处；存档格式版本另算，见 `MODEL_VERSION`）

**一个用 C 写的「白箱 AI 内核」实验**：记忆是一张**图**（词＝节点、关系＝边），推理是**图上求解 + 验证**，
思考是**逐步在图上走**，所有"改自己脑子"的动作都走一条
**提议 → 审查 → 预算 → 应用 → 审计**的受审通道。没有神经网络生成文本，没有调用大模型。

> 一句话：把"AI 怎么记住、怎么推、怎么改自己"这三件事，全部摊开成能读、能查、能复现的代码与数据。

## 快速开始

```sh
# 1) 编译（C11 + libc，约 20 秒）
gcc -std=c11 -O2 -Wall -Wextra -Wpedantic -Werror -o build_aip main.c -lm

# 2) 跑起来（model.bin 是出厂模型：约 1200 个符号节点 / 4 万条边）
./build_aip --model model.bin
你 > 猫 属于 动物          # 陈述：它当场学进图里
你 > 猫 会 飞 吗            # 提问：走关系层求解 + 验证
你 > ::help                # 所有元命令（::stats ::edges ::rel ::think ::proc ::safe …）

# 3) 跑全部看护（32 套 + 冒烟 + 自检，约 30 秒）
sh tests/all.sh
```

只想跑一套（几秒）：

```sh
sh tests/relations.sh     # 关系层：传递/否定/情态说法
sh tests/tokenop.sh       # 符号节点行为（图操作）与过程记号
sh tests/thinking.sh      # 思维循环
BIN=./build_aip sh tests/belief.sh   # 也能指定二进制
```

用一份语料训练/追加知识并另存：

```sh
./build_aip --model model.bin corpus/_corpus.txt --save model2.bin
```

## 它现在能做什么（照实说）

| 能力 | 现状 |
|---|---|
| **图记忆** | 词＋边（命中次数/角色/动作槽）。边是**共现**（"常一起出现"），**没有语义类型** ⇒ 语料是最大的瓶颈 |
| **关系层** | 11 个核心谓语（属于/有/会/喜欢/怕/吃/在/需要…）＋**动态谓语**（清单外的词现场登记）；**支持否定**（含 `不能`/`没法` 这类情态说法归一） |
| **前提** | `A —[前提]→ P → B`：三档判据（提到过 / 够得着 / 有据）；`[前提不]` 表"没人提到 P 才成立" |
| **推理** | 图上求解 + **独立复核**（`der_verify` 拿图重推一遍）；**有缺口就不下结论**；多跳/类比/反事实（假设层）都有入口 |
| **思维循环** | 把问题拆成小目标逐个查图；内建五条机制（问前提/换问法/缺前提/借最近邻/经由中间词），**顺序即优先级**；想不通的问题挂起来下轮接着想；支持回溯（一轮最多退 2 次）
| **过程记号** | 把"一件事的步骤"变成图上的对象：`[过程:X]`＋步骤/条件/否则/异常/调用/回边；能**跑**（逐步核对＋受审执行）、能**干跑**（假设世界，不动外部世界）、问"怎么做 X"时**直接给计划** |
| **他者视角** | "谁说过的"存在他名下（不污染我的知识）；四态判定（都说认/都说不认/有分歧/没人说过）；句首"他/她/它"能指回最近说话的人（默认关） |
| **写入安全** | 统一通道：**提议→审查（保留名/预算/底线）→应用→审计**；观测与缓存分开；缓存可撤销，观测不许删 |
| **外部动作** | 白名单 9 条命令（echo/cat/wc/gcc/grep/head/tail/sed/ls）＋超时＋账；过程步骤能真的调它 |
| **代码闭环** | 写 → 编译 → 看第一条错误 → 按规则表改**一次**（降级版，**不生成代码**） |

### 它能保证什么（都是设计的直接后果）

- **不具备产生幻觉的条件**：回答只可能来自图上查到的边、或图上推出来的链 —— 没有生成式模型，
  就没有"编一段像样的话"这条路；链上有缺口就明说「不知道 / 判不了」。
  （**照实说**：它会**忠实转述图里的错误** —— 图错了它就跟着错，但它不会无中生有。）
- **可泛化**：上位/类别继承（知道 `猫 属于 动物`，问动物能答出猫）、借最近邻、关系类比、前提传递，
  都是图上的算子，不是一张特例表。
- **可审计**：每个结论都留着"怎么来的"（推导链 + 缺口），每次自改都留着"谁提的 / 审查结果 / 账"
  —— `::safe`（写入审计）、`::delib`（推导链）、`::stats`（总账）随时可查。
- **查询与推理是局部操作**：答一句话只沿相关节点和它邻边走，多跳也是邻域扩展，
  不看全图。**实测口径**（`tests/speed_scale.sh`，同一批 40 问、装载只算一次）：
  边数 **209 → 41022（196×）**，每问 **808 µs → 12415 µs（15.3×）** —— **次线性，但不是常数**；
  所以别把它说成"与图规模无关"。（**代价照实说**：维护那一遍是线性的 —— 巩固/衰减/漂移采样按轮次全量扫。）
- **只有观测进图**：听到看到的（观测）与想出来沉淀的（缓存）分开记账；缓存可撤销，观测不许删。

**它做不到的**（同样照实说）：语料没写过的事推不出来；说法不在关键词/槽位表里就"听不懂"；
时间只有区间（首次/最近），没有"同时/先后不明"的判据；不会自己写代码；长文本记忆与常识仍很薄。

想看全部局限（含"怎么解"）：[`docs/局限总表.md`](docs/局限总表.md)。

## 代码地图

| 文件 | 管什么 |
|---|---|
| `main.c` | 入口 + 全部 `::` 元命令 + 语料装载 |
| `ai.h` | AI 状态机与机制：感知/学习/情绪/直觉/输出流水线开关 |
| `micro.h` | **微内核**：受审通道（提议/审查/预算/应用/审计）＋ `TOKEN_OPS[]` 行为表 |
| `token.h` | 图的底层：符号节点、边（角色/动作槽/命中）、极性、前提、顺序、词法 |
| `rel.h` | 关系层：谓语表、求解、否定/情态归一、他者宾语蕴含 |
| `derive.h` | 推导与验证：`Derivation`、缺口、`der_verify` |
| `think.h` | 思维循环：议程/机制/回溯/未解问题/空闲思考/思考对象 |
| `agent.h` | 对话流水线：触发→学习→关系→帧→检索→生成→收尾；过程执行引擎 |
| `frame.h` / `frame_io.h` | 结构化帧库（`frames.txt`） |
| `action.h` | 外部执行层（白名单＋超时＋账，默认关） |
| `code.h` | 写-跑-看错-改 的机械闭环 |
| `lex.h` | ASCII 逐字保留（写代码的前置条件） |
| `token_lang.h` | 原语（堆栈语言）＋干跑校验器 |
| `model_io.h` | 存档读写（**格式 v10**）与训练 |
| `tests/` | 32 套看护 + 冒烟 + `selfcheck`（看护的看护） |
| `tools/` | 探针与 C 级自测（`optest`/`delibtest`/`microtest`…） |
| `docs/` | 设计文档：思维循环、微内核、模型与训练、来源监控、局限总表… |
| `codes/` | 源码/测试/工具的**逐字节副本**（某些流程只读它） |

## 工程约定（这个项目的"脾气"）

- **先量后改**：任何"行为改动"先量现状 → **默认关**（与今天逐字节相同）→ A/B 对比 → 才谈翻默认。
- **看护文化**：每改一处都补断言；`tests/all.sh` 必须全绿才提交；`selfcheck` 专门检查
  "断言假绿/管道吞退出码/脚本漏进清单/对外文件带本机路径"这类**会骗人的坑**。
- **只有观测进图**：听到看到的（观测）与想出来沉淀的（缓存）分开记账，缓存可撤销。
- **结论要有据**：链上有缺口就不许说"想通了"；答不出来就说不知道。
