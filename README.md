## 1. 它是什么（和不是什么）

**是**：一张会生长的**符号图**（词＝节点、关系＝边），推理是**图上求解 + 复核**，
思考是**在图上一步步走**，自改走**提议→审查→预算→应用→审计**，写代码靠**骨架知识 + 编译反馈闭环**。

**不是**：不是大模型、不做梯度训练、不生成"像样的话"。
所以它**不具备产生幻觉的条件**——回答只可能来自图上查到的边、或图上推出来的链；链上有缺口就明说"不知道 / 判不了"。

**照实说**：它会**忠实转述图里的错误**（图错了它就跟着错），但它不会无中生有。

## 3. 记忆：符号图

**节点**（`Token`）：名字 + 边表 + 记忆状态（`ACTIVE / FADING / DORMANT / FORGOTTEN / 垃圾`）+ 派生缓存（字符切分、字符位图）。

**边**（`AssocEntry`）不是"权重"，而是带结构的记录：

| 字段 | 含义 |
|---|---|
| `main / action` | 另一端；以及"这条边在什么动作下成立"（动作槽） |
| `hits / seq` | 被观察到的次数 / 顺序 |
| `tset[4]` | **时刻集合**：这条边在哪些 tick 被观察到（不是只有首次/最近） |
| `role` | 观察 / 想象 / 推理沉淀 …（一眼看出"是听到的还是想出来的"） |
| `rel / nrel` | 语义关系的**位图**（同一对词可同时挂多种关系）+ 否定位图 |
| `mem_state` | 活跃/淡化/休眠/遗忘 |

**为什么这样设计**：可审计（每条结论能追到边）、可回收（状态机 + 垃圾标记）、可外置（`::parts evict` 把边挪磁盘）。

## 4. 推理：图上求解 + 独立复核

- **求解**：多跳 / 传递 / 类比 / 反事实（假设层）/ 前提（`A —[前提]→ P → B`，三档判据）。
- **复核**：`der_verify` 拿图**重推一遍**，不一致就降置信度或不下结论。
- **缺口**：链上缺一环 ⇒ 明说"不知道 / 判不了"，并指出缺什么（`::delib` 能看到推导链与停因）。
- **对抗**：否定（含 `不能/没法` 情态归一）、独占关系下的冲突检测（`::contradict`）。

## 5. 思考：思维循环与过程记号

**思维循环**：把问题拆小目标逐个查图，内建五条机制（问前提 / 换问法 / 缺前提 / 借最近邻 / 经由中间词），
顺序即优先级；想不通的挂起来下轮接着想；支持回溯（一轮最多退 2 次）。

**过程记号**：把"一件事的步骤"变成图上的对象（`[过程:X]` + 步骤/条件/否则/异常/调用/回边）：

- **跑**：逐步核对 + 受审执行；
- **干跑**：在假设世界里跑，不动外部世界；
- 问"怎么做 X" ⇒ 直接给计划。

`tests/tokenop.sh` 有 **414 项**断言覆盖这一层。

## 6. 自修改：受审通道

所有"改自己脑子"的动作只有一条路：

```
提议（谁想改） → 审查（保留名/预算/底线） → 预算 → 应用 → 审计（::safe 可查）
```

- **观测 ≠ 缓存**：听到看到的进观测账（不许删）；自己想出来沉淀的进缓存账（可撤销、前提没了自动失效）。
- **自修改微内核**：开关、安全点、意图/应用/拒绝/去重计数、补丁、提醒。

## 7. 语言件下沉到图

这是本项目最"反常规"的设计取向：**语言知识也当数据存**，而不是写死在代码里。

| 语言件 | 存在形式 | 运行时怎么用 | 验收 |
|---|---|---|---|
| **分词的词** | 图节点（`lexicon.txt` 的词启动时建节点）| `ai_match_word` 先 `pool_find`（图优先） | `factorymodel` 指纹 |
| **说法映射** | `擅长 --[同义]--> 会` | 抽取器 `paper_graph_canon` 先查图 | `tests/graphmap.sh` |
| **框式模式** | `以为业 --[同义]--> 吃`（模式名=前缀+后缀）| `paper_graph_cf` 先查图 | `tests/graphsink.sh` |
| **逻辑律** | `吃 --[有]--> 唯一性` | `::solve` 先查图，再退 `laws.txt` | `tests/graphsink.sh` |
| **帧** | `自由:帧:害怕X吗 --[问法/答法/填充]--> …` | `::framesync` 校验；`AIP_FRAMES_FROM_GRAPH=1` 时**从图装载** | `tests/framesink.sh` |

**为什么重要**：这些知识能随模型走（`::save` 一次带走）、能审计（`::rel` 直接看）、能教（`::ingest` 一条语句）。

## 8. 泛化：说法归一与例句归纳

**问题**：同一件事换个说法就抽不到（`是…的一种` / `可以` / `生活在` / `害怕` / `以…为食`）。

**方法（四层说法归一，全在"说法层"，不背事实）**：

1. 关系词归一：可以/能够/能→会；害怕/惧怕→怕；喜爱→喜欢；拥有/具有→有；栖息于/住在/分布于→在；是→属于；
2. 词尾归一：宾语去「的一种/一类」，主语去「生活/住」；
3. 宾语内层：`喜欢吃鱼` ⇒ 关系 `吃`、宾语 `鱼`；
4. 框式改写：`[以][宾语][为X]` ⇐⇒ `[关系词][宾语]`。

**效果**：16 句不同说法 ⇒ **14 条规范三元组**（重复自动合并），全部进**待证**（可信度 50，人确认才算数）。

**例句归纳**（`tools/induce_paraphrase.sh`）：给两条例句就能归纳出新说法族——

```
企鹅擅长游泳 → 企鹅 会 游泳     ⇒ 归纳（顺序）：擅长 → 会
蜜蜂以花蜜为生 → 蜜蜂 吃 花蜜   ⇒ 归纳（框式）：以…为生 → 吃
```

**泛化边界（实测）**：同族没见过句子 **8/10**；**没教过的新说法族 3/8**（擅长/以…为食 之外的全落空）。
⇒ 这是"**教一族会一族**"，不是"见过一种自动外推"。

## 9. 约束推理（糖果题）

「糖果推理」指以糖果为题的经典逻辑谜题（标签全错 / 真假话 / 抽屉原理 / 分配数量）。
`::solve` 实现其中的**排除法**：

```
::solve 吃 红糖果 绿糖果 蓝糖果 -- 小红 小明 小刚
  ⇒ 小刚 吃 绿糖果（行排除：该行只剩这一个未知）
  ⇒ 小明 吃 蓝糖果（列排除：该值只剩这一个主体可能）
  答案表：小红=红 小明=蓝 小刚=绿
```

- **模型**：每个主体恰好一个值、每个值至多一个主体（律可从图里读：`吃 --[有]--> 唯一性`）；
- **不硬猜**：约束不够时明说"没有能被排除法逼出来的结论"；
- **覆盖率**：①标签全错（内容判定）✅ ②真假话 ❌ ③抽屉原理 ❌ ④分配推理 ✅。

## 10. 写代码：骨架合成与教学闭环

```
任务描述 → 关键词匹配 → 骨架（任务→可编译 C，程序自带自测） → 编译 → 跑自测 → "测试全绿"
```

- `::code synth <中文描述>`：合成、编译、跑、看错、按规则改**一次**、还不过就**还原**；
- **能力实测**（`tools/code_ability.sh`）：codebench 自带 15/15；**新任务 10/15**；**难题 7/8**；合计 **32/38**；
- **可教**（`tools/teach_skeleton.sh`）：**一条骨架 ~30 秒**教会，当场编译+自测验证 ⇒ 教 8 条后 **38/38**；
- **不会瞎编**：没有匹配的骨架就明说"没有匹配的任务"，不生成编不过的程序。

## 11. 自由图符号

"草稿记忆"：临时想出来的符号，**只跟自己人连**，跟知识只**临时沾一下**，用完就回收。

```
::freesym new 草稿1        ::freesym link 草稿1 草稿2
::freesym anchor 草稿2 猫   ::freesym show/list/drop/activate
```

- **独立池**：自由符号住在单独的 `TokenPool` ⇒ **主图节点数/边数一点不变**（1282/41198 可验）；
- **挂知识走假设层**（`hypo_add`，pop 就撤）⇒ 主图**不写边**，`::rel 猫` 看不到它们；
- **不存盘**：自由池不进 `::save` ⇒ 会话结束就没了（正是"草稿"语义）；
- **稀疏激活**：`activate` 只把点名的那个放进焦点环。

## 12. 真知识工程

目标：把真实世界的代码/文档知识装进图，且**便宜、可增量、可查**。

| 组件 | 做法 |
|---|---|
| 抓取 | `tools/pipeline.sh` 管四条源（Debian / Ubuntu / PyPI / RubyGems）+ 镜像自动切换 + 看护 |
| 存储 | `.c7b` v2 分片（8 B/边）+ gzip ⇒ **7.4 B/边**；0.5B 边约 4 GB |
| 查询 | `::parts corpus rel <名字>`（单片 124 ms 含解压）、`::parts corpus find <名字> <目录>`（0.1 秒/片，511 片 ≈ 48 s）|
| 现状 | 累计 **2.4 亿条真边**（≈ 0.5B 目标的 49%）|

**边界（实测）**：`find` 是**线性**的（文本名字索引不可行：511 片要 5.4 GB）；下一步是并行扫描或 Bloom 索引。

## 13. 性能画像

| 指标 | 数值 | 说明 |
|---|---|---|
| `::rel` 图查询 | **12.5 µs** | 与图规模**无关**（4 万边与 42 万边同速）|

| 常驻内存 | **15 MB** | 同上 |
| 1.27 M 边模型 | 载入 3.25 s / 问答 189 ms / 1.37 GB | **线性**增长 |
| 灌图吞吐 | 52 632 条/秒（4 万边）→ 526 条/秒（1.27 M 边）| 随图变大下降 |

**结论**：**查询是常数级，装载与问答是线性级** —— 别把"查询快"说成"规模无关"，代价在别处。

## 14. 可审计性：四层看护

| 层 | 看护 | 抓什么 |
|---|---|---|
| 1 | `tests/all.sh`（**88 套**）| 功能回归（关系/思维/代码/推理/语言…）|
| 2 | `tests/selfcheck.sh` | **看护的看护**：清单/脚本/文档引用的 8 类坑（比如"断言撞上帮助文本""set -e 吞掉退出码"）|
| 3 | `tests/factorymodel.sh` | **结构指纹**：出厂模型节点 1282 / 边 41198，改图就红 |
| 4 | `tests/rebake.sh` + `tools/rebake.sh` | **行为基线**：13 条探针的答案快照，换模型就 diff |

**标定发现（§6.771）**：往 `model.bin` 里**只加 2 条事实（+3 节点）**，`relations` 与 `bucketload` 当场变红——
不是 bug，是**图的内容本身就是行为的一部分**（节点数会改 idf/激活/选路）。所以出厂模型是**标定产物**，
要吸收新知识就必须**显式重标定**（`tools/rebake.sh` + 逐条确认变化）。

## 15. 诚实边界

- **英文资料抽不出断言**：读得到文字（22 672 字节的论文实测），但抽取用的是中文关系词表 ⇒ 0 条待证；
- **PDF 依赖字体映射**：无 ToUnicode 的 PDF 取不到文字（实测抓到的一篇就是"字体映射 0 个"）；
- **泛化是"同族"的**：同族新句子 8/10；**跨族不行**（新说法族需归纳或补词）；
- **约束推理只做了排除法**：真假话/抽屉原理未接；
- **代码能力 = 骨架库覆盖度**：没教过的任务类型明说不会，不瞎编；
- **帧运行时默认仍读 `frames.txt`**：图装载（`AIP_FRAMES_FROM_GRAPH=1`）已验证行为一致，但默认保守；
- **跨片查找是线性的**：0.1 秒/片；
- **语料是最大瓶颈**：没写进图的事推不出来。
